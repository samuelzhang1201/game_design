# Shots and bench

`tools/snapshot_screen.gd --screen root --quiet --war-room …` drives it by REAL input (`--war-sheet`, `--war-zoom`, `--war-focus`, `--war-piece`, `--war-drag`, `--war-commit`, `--war-folio`, `--war-turn`, `--war-board`, `--war-board-click`, `--war-cell`, `--war-deploy`, `--war-leave`, `--war-room-at`, `--war-hover fx,fy` — a real resting pointer for the slip (the tool first announces the pointer to the viewport, `NOTIFICATION_VP_MOUSE_ENTER`, or the GUI drops a lone motion), `--war-focus-px x,y` — lean in on a pack point; plans: `--war-plans-demo` seeds a fixed set near `--war-focus`, `--war-plan-menu fx,fy`, `--war-plan-place`, `--war-plan-draw [side:]kind,fx1,fy1,fx2,fy2[;…]` (`sel` for fx1: from the red selection), `--war-plan-select first|hint`, `--war-plan-hover`; drawn orders: `--war-spread N` (stands N regiments in the field), `--war-box` (a real click on the blue crayon, then a real plain drag round them; `--war-box-hold` keeps the button down, the marquee in the shot), `--war-drag fx,fy` (the blue arrow for the selection), `--war-supply` (clicks the lit town nearest the end), `--war-supply-town CODE|off` (chooses that town through the confirm's `select_supply` — a documented exception to real input, the list's popup window takes no pushed pointer or key; `off` the lit town nearest the laid sheet yet off it, for the exit mark), `--war-supply-list` (opens the Supply from list, printing its rows), `--supply-front` / `--supply-front-reg CODE` / `--supply-front-before` (a broken line, with `--war-sheet` of its column), `--war-commit`, `--war-edit` (the draft pennant's Edit route…), `--war-hint` (seeds a spy report), `--war-wait N`; battle: `--battle-case field` (a real contact, its notice acknowledged through Game) with `--war-task` (the docked folio's Send task clicked for real) — a value-less flag must not be the last argument); use `--resolution WxH`, never headless. Every war run prints `war sync` (engine, map and room spot per regiment). Bench: `scenes/tools/war_room/bench.tscn --size WxH --quality TIER`.
