# WAR ROOM — the plotting table — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the WAR ROOM placeholder with a physical plotting room: one numbered map sheet laid as inked vellum over a relief on an oak table, the crown's regiments as frozen painted-tin pieces on bases, a rake that issues real `ARMY_MARCH` orders, and an open folio per regiment with a moving ink figure, an exploded view and the regiment's data.

**Architecture:** Three pure engine classes (`WarSheets`, `WarRoom`, `WarFolio`) hold every rule and figure; `scripts/war_room/` holds the 3D view (a SubViewport room, like the LEDGER's `LedgerView3D`) and its pure maths (`WarRoomTable`, `WarSheetInk`, `WarCamera`, `WarExplode`), never touching `Game`; `scripts/ui/war_room_screen.gd` lies over the map panel like `LedgerScreen`, puts cards in the left column and runs orders through the existing `ArmyOrderMenu` (the view speaks its signal contract).

**Tech Stack:** Godot 4.7, typed GDScript, Forward+, GUT; data in `data/*.csv`; art in the owner's Blender through the Blender MCP and Qwen-Image-2512 on the local ComfyUI.

**Spec:** `docs/superpowers/specs/2026-10-01-war-room-design.md`

## Global Constraints

- Typed GDScript everywhere (type hints on vars, params, returns); `snake_case` files/functions, `PascalCase` classes, past-tense signals.
- Every tuned number lives in `data/balance.csv` (`war_*`) or a `data/war_*.csv` table with a `notes` column — never a literal in a script.
- `scripts/war_room/*.gd` never contains the text `Game.` (a test scans it, like `scripts/map3d/` and `scripts/ledger3d/`).
- `scripts/engine/*.gd` never names a class declared under `scripts/ui/`, `scripts/llm/`, `scripts/map3d/` or `scripts/war_room/` (`tests/engine/test_engine_isolation.gd`).
- Engine classes are `RefCounted` with `static func`s, deterministic, no wall clock, no unseeded random.
- Authored text never names a kingdom; labels come from `repo.kingdoms[code]["label"]`.
- The view renders into a SubViewport at window px shown by a TextureRect, never a SubViewportContainer.
- Every order goes through `Game.try_execute` (via `ArmyOrderMenu._run`); a march is ordered only on a paused clock (`Game.clock_speed <= 0`).
- Positions read only `WarRoom.believed_position`; the table never reads `ArmySystem.position_of` directly.
- Whole figures shown to the player go through `UiPalette.format_int`; figures about a regiment pass `Intel.level` first.
- Art: Qwen-Image-2512 only for references (owner 2026-10-01); every Blender step in the OWNER's open Blender through the MCP, never headless; ask before queuing any generation batch beyond the one a task names.
- The shared main checkout is never switched; work happens on branch `design/war-room` in its worktree.
- Run one test file: `CC_FORCE_OFFLINE=1 /Applications/Godot.app/Contents/MacOS/Godot --headless --path . -s addons/gut/gut_cmdln.gd -gtest=res://tests/<dir>/<file>.gd -gpre_run_script=res://tests/pre_run.gd -gexit`. Full suite: `./run_tests.sh` (expected error count: 2 with the gdai plugin binaries present, else 0).

## Review Focus

- **The march is aimed while the clock runs.** Expected: the rake never appears, the tooltip/news gives `army_route_orders.csv`'s `paused_only` hint, nothing is executed; an aim in progress is withdrawn the moment play is pressed (Task 6 test, Task 11 test).
- **A regiment stands on another sheet, at sea, or off every sheet.** Expected: it is listed in the margin with its sheet numeral (or drawn on the nearest sheet when on none), and a click lays that sheet (Task 3 test `nearest sheet`, Task 9 test).
- **A conquest moves a border while the room is open.** Expected: the next lay of that sheet redraws the border (the ink cache key carries the ownership signature) — Task 5 test on the cache key.
- **A press on a piece that never moves (a click, not a drag).** Expected: it selects the piece and opens the folio; no aim is armed (Task 11 test with a drag below `war_rake_min_px`).
- **The folio for a regiment whose model lacks a clip or whose arm has no parts model.** Expected: that tab and the Take-apart button are absent, nothing errors (Task 4 `drills_for` test, Task 14 test).

### Task 2: The sheet series (`WarSheets`)

**Files:**
- Create: `scripts/engine/war_sheets.gd`
- Test: `tests/engine/test_war_sheets.gd`

**Interfaces:**
- Consumes: `repo.bal("war_sheet_w_km" | "war_sheet_h_km" | "war_sheet_overlap_km" | "war_grid_km")`, `repo.map_info`, `repo.cells`, `repo.manors`, `repo.provinces`, `repo.kingdoms`, `MapTerrain.is_water`, `MapTerrain.cell_center`.
- Produces:
  - `WarSheets.layout(width: float, height: float, w: float, h: float, overlap: float) -> Array[Rect2]` — every rect of the full grid, row-major, the last of each row/column held to the edge.
  - `WarSheets.series(repo) -> Array` of sheets `{index: int, numeral: String, name: String, kingdom: String, rect: Rect2}` (pack px), sea-only sheets skipped, `index` 0-based in that order, cached per repo.
  - `WarSheets.px_per_unit(repo) -> float` (pack px per unit of the pack's measure).
  - `WarSheets.sheet_of(repo, px: Vector2) -> int` — index of the sheet holding `px` whose centre is nearest; else the sheet whose rect is nearest.
  - `WarSheets.grid_ref(repo, sheet: Dictionary, px: Vector2) -> String` — `"III · C7"`.
  - `WarSheets.roman(n: int) -> String`.
  - `WarSheets.neighbours(repo, index: int) -> Dictionary` — `{"n"|"s"|"e"|"w": index}` for the sheets sharing an edge band.
  - `WarSheets.forget() -> void`.

```gdscript
# tests/engine/test_war_sheets.gd
extends GutTest
## The numbered map series (spec 2026-10-01-war-room-design §2).

var repo: DataRepository


func before_all() -> void:
	repo = DataRepository.load_all("res://data")
	WarSheets.forget()


func test_beria_cuts_into_four_by_two_held_to_the_edges() -> void:
	# 2560 x 929, sheets 670 x 485, overlap 40: stride 630 / 445.
	# cols ceil((2560-40)/630) = 4 -> 0, 630, 1260, then min(1890, 2560-670=1890)
	# rows ceil((929-40)/445) = 2 -> 0, then min(445, 929-485=444) = 444
	var rects := WarSheets.layout(2560.0, 929.0, 670.0, 485.0, 40.0)
	assert_eq(rects.size(), 8)
	assert_eq(rects[0], Rect2(0, 0, 670, 485))
	assert_eq(rects[3], Rect2(1890, 0, 670, 485))
	assert_eq(rects[4], Rect2(0, 444, 670, 485))
	assert_eq(rects[7], Rect2(1890, 444, 670, 485))


func test_a_map_smaller_than_a_sheet_is_one_sheet_at_the_origin() -> void:
	var rects := WarSheets.layout(300.0, 200.0, 670.0, 485.0, 40.0)
	assert_eq(rects, [Rect2(0, 0, 670, 485)])


func test_roman_numerals() -> void:
	assert_eq(WarSheets.roman(1), "I")
	assert_eq(WarSheets.roman(4), "IV")
	assert_eq(WarSheets.roman(9), "IX")
	assert_eq(WarSheets.roman(14), "XIV")


func test_the_series_keeps_only_sheets_with_land_numbered_in_order() -> void:
	var series := WarSheets.series(repo)
```

```gdscript
# scripts/engine/war_sheets.gd
class_name WarSheets
extends RefCounted
## The WAR ROOM's numbered map series (owner 2026-10-01, spec
## 2026-10-01-war-room-design §2): the pack cut into equal sheets at ONE
## scale, neighbours overlapping, numbered in Roman numerals row by row from
## the north-west, each named after the kingdom with the most land on it by
## the STARTING border, and a place written "III · C7". Generated from the
## pack alone; no pack is named. Pure and cached per repository.

static var _cache: Dictionary = {}


static func forget() -> void:
	_cache.clear()


## Pack px per unit of the pack's own measure (map_info distance_scale is
## units per px), so the war_* sizes are in the measure the scale bar reads.
static func px_per_unit(repo: DataRepository) -> float:
	return 1.0 / maxf(float(repo.map_info.get("distance_scale", "1")), 0.0001)


## Every sheet rect of the full grid, row-major: a stride of the size less the
## overlap, as many as cover the map, the last of each run held to the edge so
## no sheet runs off it. A map smaller than a sheet is one sheet at the origin.
static func layout(width: float, height: float, w: float, h: float, overlap: float) -> Array[Rect2]:
	var xs := _starts(width, w, overlap)
	var ys := _starts(height, h, overlap)
	var out: Array[Rect2] = []
	for y in ys:
		for x in xs:
			out.append(Rect2(x, y, w, h))
	return out


static func _starts(span: float, size: float, overlap: float) -> Array[float]:
	if span <= size:
		return [0.0]
	var stride := maxf(size - overlap, 1.0)
	var n := int(ceil((span - overlap) / stride))
	var out: Array[float] = []
	for i in n:
		out.append(minf(float(i) * stride, span - size))
	return out


## The series: sheets with land, in order, numbered and named.
static func series(repo: DataRepository) -> Array:
	var key := repo.get_instance_id()
	if _cache.has(key):
		return _cache[key]
	var k := px_per_unit(repo)
	var rects := layout(float(repo.map_info.get("width", "0")), float(repo.map_info.get("height", "0")),
		repo.bal("war_sheet_w_km") * k, repo.bal("war_sheet_h_km") * k, repo.bal("war_sheet_overlap_km") * k)
	var centres := _land_centres(repo)
	var out: Array = []
	for r: Rect2 in rects:
		var tally: Dictionary = {}
		for c: Dictionary in centres:
			if r.has_point(c["at"]):
				tally[c["kingdom"]] = int(tally.get(c["kingdom"], 0)) + 1
		if tally.is_empty():
			continue
		var best := ""
		for kd: String in tally:
			if best == "" or int(tally[kd]) > int(tally[best]) or (int(tally[kd]) == int(tally[best]) and kd < best):
				best = kd
		var i := out.size()
		out.append({"index": i, "numeral": roman(i + 1), "kingdom": best,
			"name": String((repo.kingdoms.get(best, {}) as Dictionary).get("label", best)), "rect": r})
	_cache[key] = out
	return out


## Each land cell's centre and its province's starting kingdom.
static func _land_centres(repo: DataRepository) -> Array:
	var out: Array = []
	var ids: Array = repo.cells.keys()
	ids.sort()
	for id: int in ids:
		var cell: Dictionary = repo.cells[id]
		if MapTerrain.is_water(cell) or (cell["vertex_ids"] as PackedInt32Array).size() < 3:
			continue
		var prov := String((repo.manors.get(id, {}) as Dictionary).get("province_code", ""))
		var kd := String((repo.provinces.get(prov, {}) as Dictionary).get("kingdom_code", ""))
		if kd == "":
			continue
		out.append({"at": MapTerrain.cell_center(repo, cell), "kingdom": kd})
	return out


static func roman(n: int) -> String:
	var vals := [1000, 900, 500, 400, 100, 90, 50, 40, 10, 9, 5, 4, 1]
	var syms := ["M", "CM", "D", "CD", "C", "XC", "L", "XL", "X", "IX", "V", "IV", "I"]
	var out := ""
	var left := n
	for i in vals.size():
		while left >= int(vals[i]):
			out += String(syms[i])
			left -= int(vals[i])
	return out


## The sheet holding `px` whose centre is nearest (in the overlap both hold
## it); a point on no sheet goes to the sheet whose rect is nearest.
static func sheet_of(repo: DataRepository, px: Vector2) -> int:
	var best := -1
	var best_d := INF
	var holding := false
	for s: Dictionary in series(repo):
		var r: Rect2 = s["rect"]
		var inside := r.has_point(px)
		var d := px.distance_squared_to(r.get_center()) if inside else _rect_gap(r, px)
		if (inside and not holding) or ((inside == holding) and d < best_d):
			best = int(s["index"])
			best_d = d
			holding = holding or inside
	return best


static func _rect_gap(r: Rect2, p: Vector2) -> float:
	var q := Vector2(clampf(p.x, r.position.x, r.end.x), clampf(p.y, r.position.y, r.end.y))
	return 1.0e12 + p.distance_squared_to(q)  # always behind any sheet that holds it


## "III · C7": the sheet's numeral, the column letter (A from the west edge)
## and row number (1 from the north edge) of war_grid_km squares.
static func grid_ref(repo: DataRepository, sheet: Dictionary, px: Vector2) -> String:
	var r: Rect2 = sheet["rect"]
	var g := repo.bal("war_grid_km") * px_per_unit(repo)
	var col := clampi(int(floor((px.x - r.position.x) / g)), 0, 25)
	var row := maxi(int(floor((px.y - r.position.y) / g)), 0) + 1
	return "%s · %s%d" % [sheet["numeral"], char(65 + col), row]


## The sheets beside `index`: the nearest one each way whose rect overlaps
## this one's edge band.
static func neighbours(repo: DataRepository, index: int) -> Dictionary:
	var all := series(repo)
	if index < 0 or index >= all.size():
		return {}
	var me: Rect2 = all[index]["rect"]
	var out: Dictionary = {}
	var dists: Dictionary = {}
	for s: Dictionary in all:
		var r: Rect2 = s["rect"]
		if int(s["index"]) == index:
			continue
		var dc := r.get_center() - me.get_center()
		var dir := ""
		if absf(dc.x) > absf(dc.y):
			dir = "e" if dc.x > 0.0 else "w"
			if r.position.y >= me.end.y or r.end.y <= me.position.y:
				continue
		else:
			dir = "s" if dc.y > 0.0 else "n"
			if r.position.x >= me.end.x or r.end.x <= me.position.x:
				continue
		var d := dc.length()
		if not dists.has(dir) or d < float(dists[dir]):
			dists[dir] = d
			out[dir] = int(s["index"])
	return out
```

```gdscript
class_name WarRoom
extends RefCounted
## What the WAR ROOM's plotting table shows (owner 2026-10-01, spec
## 2026-10-01-war-room-design §3). A piece stands where we KNOW the regiment
## stands: believed_position is the one place the table reads, so intel P2's
## blur (the last ARRIVED report's place) lands here and nowhere else. The
## enemy's ghosts are believed_hosts — empty until the raid host exists.


static func believed_position(repo: DataRepository, state: GameState, reg: Dictionary) -> Vector2:
	return ArmySystem.position_of(repo, state, reg)


## P2 fills this with {code, at, low, high, source, day}; the table draws each
## as a translucent piece over an inked ring of uncertainty.
static func believed_hosts(_repo: DataRepository, _state: GameState) -> Array:
	return []


## The crown's regiments as pieces: code, believed place, naval, home sheet.
static func pieces(repo: DataRepository, state: GameState) -> Array:
	var out: Array = []
	for reg: Dictionary in MapObjects.regiments_of(repo, repo.resolve_realm("player_realm")):
		var at := believed_position(repo, state, reg)
		out.append({"code": String(reg["regiment_code"]), "at": at,
			"naval": String(reg.get("is_naval", "0")) == "1", "sheet": WarSheets.sheet_of(repo, at)})
	out.sort_custom(func(a: Dictionary, b: Dictionary) -> bool: return String(a["code"]) < String(b["code"]))
	return out


## On a sheet: inside its rect, or on no sheet at all and this the nearest.
static func on_sheet(repo: DataRepository, state: GameState, sheet_index: int) -> Array:
	var all := WarSheets.series(repo)
	if sheet_index < 0 or sheet_index >= all.size():
		return []
	var r: Rect2 = all[sheet_index]["rect"]
	return pieces(repo, state).filter(func(p: Dictionary) -> bool:
		return r.has_point(p["at"]) or (not _on_any(all, p["at"]) and int(p["sheet"]) == sheet_index))


static func off_sheet(repo: DataRepository, state: GameState, sheet_index: int) -> Array:
	var on := on_sheet(repo, state, sheet_index).map(func(p: Dictionary) -> String: return String(p["code"]))
	return pieces(repo, state).filter(func(p: Dictionary) -> bool: return not String(p["code"]) in on)


static func _on_any(all: Array, at: Vector2) -> bool:
	for s: Dictionary in all:
		if (s["rect"] as Rect2).has_point(at):
			return true
	return false


## The clip a frozen piece is posed in.
static func pose_action(order: String) -> String:
	match order:
		ArmySystem.ORDER_MARCH:
			return "MARCH"
		ArmySystem.ORDER_GARRISON:
			return "GARRISON"
	return "STANDBY"


## The pennant over a march order: where the newest courier carries it
## ("riding"), else the march the column is under ("received"); {} when
## neither.
static func pennant_of(repo: DataRepository, state: GameState, code: String) -> Dictionary:
	var c := CourierSystem.pending_for(state, code)
	if not c.is_empty():
		var order: Dictionary = c.get("order", {})
		if String(order.get("action_code", "")) == "ARMY_MARCH":
			return {"at": ArmySystem.metres_to_pack(repo, Vector2i(int(order["x_m"]), int(order["y_m"]))),
				"status": "riding"}
		return {}
	if ArmySystem.order_of(repo, state, code) == ArmySystem.ORDER_MARCH:
		return {"at": ArmySystem.destination_of(repo, state, code), "status": "received"}
	return {}


## The slip pinned beside a piece: heads under arms and whole months of stores.
static func tag_text(repo: DataRepository, state: GameState, code: String) -> String:
	var reg := ArmySystem.regiment(repo, code)
	var heads := group(ArmySystem.headcount(repo, reg))
	var st := ArmySystem.state_of(repo, state, code)
	var use := ArmySystem.supply_use(repo, reg, state)
	if st.is_empty() or use <= 0:
		return heads
	@warning_ignore("integer_division")  # whole months in hand
	return "%s · stores %d mo" % [heads, int(st["supplies"]) / use]


static func group(n: int) -> String:
	var digits := str(absi(n))
	var out := ""
	while digits.length() > 3:
		out = "," + digits.substr(digits.length() - 3) + out
		digits = digits.substr(0, digits.length() - 3)
	return ("-" if n < 0 else "") + digits + out
```

```gdscript
class_name WarFolio
extends RefCounted
## The WAR ROOM folio's right page and drill tabs (owner 2026-10-01, spec

static func has_builder(key: String) -> bool:
	return key in BUILDERS


static func sections(repo: DataRepository, state: GameState, code: String) -> Array:
	var reg := ArmySystem.regiment(repo, code)
	if reg.is_empty():
		return []
	if Intel.level(repo, state, {"kind": "regiment", "code": code}) != "full":
		return [{"key": "composition", "label": _label_of(repo, "composition"),

	return out

	for i in drills.size():

			return i
	return 0
```

```gdscript
## §2): a sheet laid war_table_w_m wide, centred on the table's origin, x east
## and z south as the pack's own y; the relief from the pack's height field in
## REAL metres, raised by war_relief_exaggeration over the table's true scale.

static func depth_m(sheet_rect: Rect2, table_w: float) -> float:
	return table_w * sheet_rect.size.y / sheet_rect.size.x


static func to_table(sheet_rect: Rect2, table_w: float, px: Vector2) -> Vector2:
	var s := table_w / sheet_rect.size.x
	return (px - sheet_rect.position) * s - Vector2(table_w, depth_m(sheet_rect, table_w)) * 0.5


static func from_table(sheet_rect: Rect2, table_w: float, xz: Vector2) -> Vector2:
	var s := table_w / sheet_rect.size.x
	return (xz + Vector2(table_w, depth_m(sheet_rect, table_w)) * 0.5) / s + sheet_rect.position


static func metres_of_relief(repo: DataRepository, value_0_255: float) -> float:
	var units := value_0_255 * 100.0 / 255.0
	return maxf(0.0, (units - repo.bal("elevation_sea_level")) * repo.bal("elevation_m_per_unit"))


static func heights(repo: DataRepository, relief: Image, sheet_rect: Rect2, nx: int, nz: int) -> PackedFloat32Array:
	var out := PackedFloat32Array()
	out.resize(nx * nz)
	var scale := maxf(repo.bal("map_relief_scale"), 1.0)
	var w := relief.get_width()
	var h := relief.get_height()
	for j in nz:
		for i in nx:
			var px := sheet_rect.position + sheet_rect.size * Vector2(float(i) / float(nx - 1), float(j) / float(nz - 1))
			var x := clampi(int(px.x / scale), 0, w - 1)
			var y := clampi(int(px.y / scale), 0, h - 1)
			out[j * nx + i] = metres_of_relief(repo, relief.get_pixel(x, y).r * 255.0)
	return out


static func table_y(repo: DataRepository, sheet_rect: Rect2, table_w: float, metres: float) -> float:
	var metres_per_px := float(ArmySystem.metres_per_pack_px(repo))
	return metres / metres_per_px * (table_w / sheet_rect.size.x) * repo.bal("war_relief_exaggeration")


static func height_at(heights_m: PackedFloat32Array, nx: int, nz: int, table_w: float, depth: float,
		xz: Vector2) -> float:
	var u := clampf((xz.x / table_w + 0.5) * float(nx - 1), 0.0, float(nx - 1))
	var v := clampf((xz.y / depth + 0.5) * float(nz - 1), 0.0, float(nz - 1))
	var i0 := mini(int(u), nx - 2)
	var j0 := mini(int(v), nz - 2)
	var fu := u - float(i0)
	var fv := v - float(j0)
	var a := lerpf(heights_m[j0 * nx + i0], heights_m[j0 * nx + i0 + 1], fu)
	var b := lerpf(heights_m[(j0 + 1) * nx + i0], heights_m[(j0 + 1) * nx + i0 + 1], fu)
	return lerpf(a, b, fv)


static func ray_hit(origin: Vector3, dir: Vector3, y_at: Callable) -> Vector3:
	if dir.y >= -0.000001:
		return Vector3.INF
	var y := 0.0
	var p := origin
	for _i in 4:
		var t := (y - origin.y) / dir.y
		p = origin + dir * t
		y = float(y_at.call(Vector2(p.x, p.z)))
	return Vector3(p.x, y, p.z)


static func build_mesh(heights_m: PackedFloat32Array, nx: int, nz: int, table_w: float, depth: float,
		y_scale: float) -> ArrayMesh:
	var verts := PackedVector3Array()
	var uvs := PackedVector2Array()
	var uv2s := PackedVector2Array()
	var idx := PackedInt32Array()
	for j in nz:
		for i in nx:
			var u := float(i) / float(nx - 1)
			var v := float(j) / float(nz - 1)
			var m := heights_m[j * nx + i]
			verts.append(Vector3((u - 0.5) * table_w, m * y_scale, (v - 0.5) * depth))
			uvs.append(Vector2(u, v))
			uv2s.append(Vector2(m, 0.0))
	for j in nz - 1:
		for i in nx - 1:
			var a := j * nx + i
			idx.append_array([a, a + 1, a + nx, a + 1, a + nx + 1, a + nx])
	var arrays := []
	arrays.resize(Mesh.ARRAY_MAX)
	arrays[Mesh.ARRAY_VERTEX] = verts
	arrays[Mesh.ARRAY_TEX_UV] = uvs
	arrays[Mesh.ARRAY_TEX_UV2] = uv2s
	arrays[Mesh.ARRAY_INDEX] = idx
	var st := SurfaceTool.new()
	var mesh := ArrayMesh.new()
	mesh.add_surface_from_arrays(Mesh.PRIMITIVE_TRIANGLES, arrays)
	st.create_from(mesh, 0)
	st.generate_normals()
	return st.commit()
```

```gdscript
class_name WarSheetInk
extends RefCounted
## What is inked on a laid sheet (owner 2026-10-01, spec 2026-10-01-war-room-design
## §2), in TEXTURE px — tex_px across the sheet's width, its height at the same
## scale — so WarInkPainter only draws. Roads solid, trails dashed, rivers in
## blue ink, the coast, each kingdom's LIVE outline (MapOwnership), the province
## seams, towns by tier with names, peaks with heights. Contours and the grid
## are the shader's, not here.

const TOWN_TIERS := {"village": 0, "town": 1, "fort": 1, "city": 2, "capital": 3}


static func cache_key(state: GameState, sheet_index: int) -> int:
	return hash([sheet_index, state.province_owner.hash(), state.manor_province.hash()])


static func _to_tex(r: Rect2, k: float, poly: PackedVector2Array) -> PackedVector2Array:
	var out := PackedVector2Array()
	out.resize(poly.size())
	for i in poly.size():
		out[i] = (poly[i] - r.position) * k
	return out


static func _touches(r: Rect2, poly: PackedVector2Array) -> bool:
	for p in poly:
		if r.has_point(p):
			return true
	return false


static func strokes(repo: DataRepository, state: GameState, sheet: Dictionary, tex_px: int) -> Dictionary:
	var r: Rect2 = sheet["rect"]
	var k := float(tex_px) / r.size.x
	var out := {"roads": [], "trails": [], "rivers": [], "coasts": [], "borders": [], "seams": [],
		"towns": [], "peaks": []}
	for row: Dictionary in repo.routes.values():
		var poly: PackedVector2Array = row["polyline"]
		var group := String(row.get("group", ""))
		if group in ["roads", "trails"] and _touches(r, poly):
			(out[group] as Array).append(_to_tex(r, k, poly))
	for row: Dictionary in repo.rivers.values():
		var poly: PackedVector2Array = row["polyline"]
		if _touches(r, poly):
			(out["rivers"] as Array).append(_to_tex(r, k, poly))
	for row: Dictionary in repo.coasts:
		var poly: PackedVector2Array = row["polyline"]
		if _touches(r, poly):
			(out["coasts"] as Array).append(_to_tex(r, k, poly))
	var kingdoms: Array = repo.kingdoms.keys()
	kingdoms.sort()
	for kd: String in kingdoms:
		var loops: Array = []
		for loop: PackedVector2Array in MapOwnership.outline_of(repo, state, kd):
			if _touches(r, loop):
				loops.append(_to_tex(r, k, loop))
		if not loops.is_empty():
			(out["borders"] as Array).append({"kingdom": kd, "color": MapPalette.color_of(repo, kd), "loops": loops})
		for seam: PackedVector2Array in MapOwnership.seams_of(repo, state, kd):
			if _touches(r, seam):
				(out["seams"] as Array).append(_to_tex(r, k, seam))
	var codes: Array = repo.burgs.keys()
	codes.sort()
	for code: String in codes:
		var b: Dictionary = repo.burgs[code]
		var at := Vector2(float(b["x"]), float(b["y"]))
		if not r.has_point(at):
			continue
		var tier := 3 if String(b.get("is_capital", "0")) == "1" else int(TOWN_TIERS.get(String(b.get("group", "")), 0))
		(out["towns"] as Array).append({"at": (at - r.position) * k, "tier": tier, "label": String(b["label"])})
	for m: Dictionary in Elevation.landmarks(repo):
		if String(m["kind"]) != "high":
			continue
		var at := MapTerrain.cell_center(repo, repo.cells[int(m["cell"])])
		if r.has_point(at):
			(out["peaks"] as Array).append({"at": (at - r.position) * k, "metres": int(m["metres"])})
	return out


static func dashed(poly: PackedVector2Array, on: float, off: float) -> Array[PackedVector2Array]:
	var out: Array[PackedVector2Array] = []
	var drawing := true
	var left := on
	var cur := PackedVector2Array()
	if poly.size() < 2:
		return out
	cur.append(poly[0])
	for i in range(1, poly.size()):
		var a := poly[i - 1]
		var b := poly[i]
		var seg := a.distance_to(b)
		var pos := 0.0
		while seg - pos > left:
			pos += left
			var p := a.lerp(b, pos / seg)
			if drawing:
				cur.append(p)
				out.append(cur)
				cur = PackedVector2Array()
			else:
				cur = PackedVector2Array([p])
			drawing = not drawing
			left = on if drawing else off
		left -= seg - pos
		if drawing:
			cur.append(b)
	if drawing and cur.size() >= 2:
		out.append(cur)
	return out
```

```gdscript
# scripts/war_room/war_camera.gd
class_name WarCamera
extends RefCounted
## The standing officer's view over the plotting table (spec
## 2026-10-01-war-room-design §1): an orbit about a point on the table, from
## the south (the sheet's foot) by default, its turn held within yaw_max so the
## room is built only where it is seen; the wheel leans in about the pointer.

var target := Vector3.ZERO
var distance := 1.6
var pitch_deg := 52.0
var yaw_deg := 0.0
var min_distance := 0.12
var max_distance := 2.4
var yaw_max := 30.0
var bounds := Rect2(-0.7, -0.5, 1.4, 1.0)


func transform() -> Transform3D:
	var p := deg_to_rad(pitch_deg)
	var y := deg_to_rad(yaw_deg)
	var back := Vector3(sin(y) * cos(p), sin(p), cos(y) * cos(p)) * distance
	var origin := target + back
	return Transform3D(Basis.looking_at(target - origin, Vector3.UP), origin)


## Lean toward (factor < 1) or back from `ground`: the distance scales and the
## target walks the same share toward the point, so the point holds its bearing.
func zoom_about(ground: Vector3, factor: float) -> void:
	var d := clampf(distance * factor, min_distance, max_distance)
	var share := 1.0 - d / distance
	target = target.lerp(Vector3(ground.x, target.y, ground.z), share)
	distance = d
	_clamp()


func pan(delta_xz: Vector2) -> void:
	target += Vector3(delta_xz.x, 0.0, delta_xz.y)
	_clamp()


func turn(delta_deg: float) -> void:
	yaw_deg = clampf(yaw_deg + delta_deg, -yaw_max, yaw_max)


func _clamp() -> void:
	target.x = clampf(target.x, bounds.position.x, bounds.end.x)
	target.z = clampf(target.z, bounds.position.y, bounds.end.y)
```

```gdscript
# scripts/war_room/war_ink_painter.gd
class_name WarInkPainter
extends Node2D
## Draws a sheet's WarSheetInk strokes ONCE into its SubViewport (spec
## 2026-10-01-war-room-design §2): the view reads the texture back and caches
## it by WarSheetInk.cache_key. Clear background: the vellum is the shader's.

var ink: Dictionary = {}
var pal: Dictionary = {}
var px: Dictionary = {}   # the war_ink_* widths, by short key
var font: Font


func paint(p_ink: Dictionary, p_pal: Dictionary, p_px: Dictionary, p_font: Font) -> void:
	ink = p_ink
	pal = p_pal
	px = p_px
	font = p_font
	queue_redraw()


func _draw() -> void:
	if ink.is_empty():
		return
	var c_ink: Color = pal["ink"]
	var c_faint: Color = pal["ink_faint"]
	for b: Dictionary in ink["borders"]:
		var band: Color = (b["color"] as Color)
		band.a = 0.28
		for loop: PackedVector2Array in b["loops"]:
			draw_polyline(_closed(loop), band, float(px["band"]), true)
	for poly: PackedVector2Array in ink["coasts"]:
		draw_polyline(poly, pal["sea_ink"], float(px["coast"]), true)
	for poly: PackedVector2Array in ink["rivers"]:
		draw_polyline(poly, pal["river_ink"], float(px["river"]), true)
	for poly: PackedVector2Array in ink["seams"]:
		for d: PackedVector2Array in WarSheetInk.dashed(poly, float(px["dash"]) * 0.5, float(px["gap"])):
			draw_polyline(d, c_faint, float(px["seam"]), true)
	for b: Dictionary in ink["borders"]:
		for loop: PackedVector2Array in b["loops"]:
			var parts := WarSheetInk.dashed(_closed(loop), float(px["dash"]), float(px["gap"]))
			for i in parts.size():
				draw_polyline(parts[i], c_ink, float(px["border"]), true)
				if i + 1 < parts.size():  # the dot between dashes
					draw_circle(parts[i][parts[i].size() - 1].lerp(parts[i + 1][0], 0.5), float(px["border"]) * 0.6, c_ink)
	for poly: PackedVector2Array in ink["trails"]:
		for d: PackedVector2Array in WarSheetInk.dashed(poly, float(px["dash"]), float(px["gap"])):
			draw_polyline(d, c_ink, float(px["trail"]), true)
	for poly: PackedVector2Array in ink["roads"]:
		draw_polyline(poly, c_ink, float(px["road"]), true)
	for t: Dictionary in ink["towns"]:
		var r := float(px["town"]) * (1.0 + 0.5 * float(int(t["tier"])))
		draw_arc(t["at"], r, 0.0, TAU, 32, c_ink, 3.0, true)
		if int(t["tier"]) >= 2:
			draw_circle(t["at"], r * 0.35, c_ink)
		draw_string(font, (t["at"] as Vector2) + Vector2(r + 6.0, float(px["label"]) * 0.35), String(t["label"]),
			HORIZONTAL_ALIGNMENT_LEFT, -1, int(px["label"]), c_ink)
	for p: Dictionary in ink["peaks"]:

		var s := float(px["town"])
```

```glsl
// scenes/war_room/war_table.gdshader
// The laid sheet (spec 2026-10-01-war-room-design §2): vellum over the relief,
// contours from the vertex's REAL metres (UV2.x), the lettered grid, the paper's
// age toward the edges, and the sheet's ink texture over it all. Sharp at
// every lean: lines are drawn by fwidth, not sampled.
shader_type spatial;
render_mode cull_disabled;

uniform sampler2D ink_tex : source_color, filter_linear_mipmap_anisotropic;
uniform vec4 paper : source_color = vec4(0.914, 0.863, 0.753, 1.0);
uniform vec4 paper_age : source_color = vec4(0.788, 0.698, 0.541, 1.0);
uniform vec4 ink : source_color = vec4(0.169, 0.129, 0.094, 1.0);
uniform vec4 sea_ink : source_color = vec4(0.306, 0.416, 0.471, 1.0);
uniform float contour_m = 200.0;
uniform float index_every = 5.0;
uniform vec2 grid_cells = vec2(16.75, 12.125); // sheet size / grid square
uniform float tex_aspect = 0.724;              // sheet h / w: the ink texture's used height

varying float metres;

void vertex() {
	metres = UV2.x;
}

float line_at(float v, float width_px) {
	float d = abs(fract(v - 0.5) - 0.5) / max(fwidth(v), 1e-5);
	return 1.0 - clamp(d - width_px * 0.5 + 0.5, 0.0, 1.0);
}

void fragment() {
	vec3 col = paper.rgb;
	float edge = max(abs(UV.x - 0.5), abs(UV.y - 0.5)) * 2.0;
	col = mix(col, paper_age.rgb, smoothstep(0.75, 1.0, edge) * 0.6);
	if (metres <= 0.0) {
		// the sea: fine coastal hatching, fading off the shore by height-less ground
		float hatch = line_at(UV.y * 900.0, 0.8);
		col = mix(col, sea_ink.rgb, hatch * 0.35);
	} else {
		float c = line_at(metres / contour_m, 0.9);
		float idx = line_at(metres / (contour_m * index_every), 1.8);
		col = mix(col, ink.rgb, max(c * 0.45, idx * 0.8));
	}
	vec2 g = UV * grid_cells;
	float grid = max(line_at(g.x, 0.7), line_at(g.y, 0.7));
	col = mix(col, ink.rgb, grid * 0.25);
	vec4 inked = texture(ink_tex, vec2(UV.x, UV.y * tex_aspect));
	col = mix(col, inked.rgb, inked.a);
	ALBEDO = col;
	ROUGHNESS = 0.9;
}
```

```gdscript
# scripts/war_room/war_index_chart.gd
class_name WarIndexChart
extends RefCounted
## The sheet index on the war room's wall (spec 2026-10-01-war-room-design §2):
## the island as inked dots, every sheet's frame and numeral; a click on it
## lays that sheet. Pure: an Image and a pick.


static func image(repo: DataRepository, px: int) -> Image:
	var w := float(repo.map_info.get("width", "1"))
	var h := float(repo.map_info.get("height", "1"))
	var ih := int(round(float(px) * h / w))
	var img := Image.create(px, ih, true, Image.FORMAT_RGBA8)
	img.fill(repo.war_palette["paper"])
	var k := float(px) / w
	var ink: Color = repo.war_palette["ink"]
	for id: int in repo.cells:
		var cell: Dictionary = repo.cells[id]
		if MapTerrain.is_water(cell) or (cell["vertex_ids"] as PackedInt32Array).size() < 3:
			continue
		var c := MapTerrain.cell_center(repo, cell) * k
		img.fill_rect(Rect2i(int(c.x), int(c.y), 2, 2), ink)
	var rubric: Color = repo.war_palette["rubric"]
	for s: Dictionary in WarSheets.series(repo):
		var r: Rect2 = s["rect"]
		var a := Vector2i(r.position * k)
		var b := Vector2i(r.end * k) - Vector2i(1, 1)
		img.fill_rect(Rect2i(a.x, a.y, b.x - a.x, 2), rubric)
		img.fill_rect(Rect2i(a.x, b.y - 1, b.x - a.x, 2), rubric)
		img.fill_rect(Rect2i(a.x, a.y, 2, b.y - a.y), rubric)
		img.fill_rect(Rect2i(b.x - 1, a.y, 2, b.y - a.y), rubric)
	img.generate_mipmaps()
	return img


static func sheet_at_uv(repo: DataRepository, uv: Vector2) -> int:
	if uv.x < 0.0 or uv.y < 0.0 or uv.x > 1.0 or uv.y > 1.0:
		return -1
	var p := uv * Vector2(float(repo.map_info.get("width", "1")), float(repo.map_info.get("height", "1")))
	return WarSheets.sheet_of(repo, p)
```

```glsl
// §3): the model's own albedo posterised into a few flat paint colours, its
// raised edges worn through to grey tin, under a thin varnish.
shader_type spatial;

uniform sampler2D albedo_tex : source_color, filter_linear_mipmap;
uniform vec4 albedo_tint : source_color = vec4(1.0);
uniform bool has_tex = true;
uniform float levels = 5.0;

	METALLIC = mix(0.05, 0.85, worn);
	ROUGHNESS = mix(0.38, 0.28, worn);   // the varnish
	SPECULAR = 0.5;
```

```gdscript
# scripts/war_room/war_pieces.gd
class_name WarPieces
extends Node3D
## The crown's regiments as painted tin miniatures on bases (owner 2026-10-01,
## spec 2026-10-01-war-room-design §3): 9 / 6 / 3 figures of the regiment's
## chief arm frozen in its order's pose, a base painted the realm's colour with
## a brass name plate and the house's arms, a paper tag on a pin. Each stands
## where WarRoom.believed_position puts it; when that moves, the plotter's rake
## pushes it there over war_plot_push_s. Never reaches the Game autoload.

const TIN := preload("res://scenes/war_room/materials/tin_miniature.tres")

var _repo: DataRepository
var _view: WarRoomView
var _sig: Dictionary = {}     # code -> [pose, figures] it was built with
var _push: Dictionary = {}    # code -> {from: Vector3, to: Vector3, left: float}
var _scenes: Dictionary = {}  # model path -> PackedScene


func setup(repo: DataRepository, view: WarRoomView) -> void:
	_repo = repo
	_view = view


func piece(code: String) -> Node3D:
	return get_node_or_null(NodePath(code)) as Node3D


func rebuild(state: GameState) -> void:
	for c in get_children():
		remove_child(c)
		c.queue_free()
	_sig.clear()
	_push.clear()
	for p: Dictionary in WarRoom.on_sheet(_repo, state, _view.sheet_index()):
		var node := _build(state, String(p["code"]), bool(p["naval"]))
		node.position = _view.table_point(p["at"])
		add_child(node)
		_pose(state, String(p["code"]), node)


func update(state: GameState) -> void:
	var on := WarRoom.on_sheet(_repo, state, _view.sheet_index())
	var keep: Dictionary = {}
	for p: Dictionary in on:
		var code := String(p["code"])
		keep[code] = true
		var want := _view.table_point(p["at"])
		var node := piece(code)
		var sig := _signature(state, code)
		if node != null and sig != _sig.get(code, []):
			var at := node.position
			remove_child(node)
			node.queue_free()
			node = null
			var fresh := _build(state, code, bool(p["naval"]))
			fresh.position = at
			add_child(fresh)
			_pose(state, code, fresh)
			node = fresh
		if node == null:
			node = _build(state, code, bool(p["naval"]))
			node.position = want
			add_child(node)
			_pose(state, code, node)
		elif node.position.distance_to(want) > 0.00001:
			_push[code] = {"from": node.position, "to": want, "left": _repo.bal("war_plot_push_s")}
			var heading := Vector2(want.x - node.position.x, want.z - node.position.z)
			if heading.length() > 0.00001:
				node.rotation.y = atan2(-heading.x, -heading.y)
		(node.get_node("Tag") as Label3D).text = WarRoom.tag_text(_repo, state, code)
	for c: Node in get_children():
		if not keep.has(String(c.name)):
			remove_child(c)
			c.queue_free()


func settle() -> void:
	for code: String in _push:
		var n := piece(code)
		if n != null:
			n.position = _push[code]["to"]
	_push.clear()


func _process(delta: float) -> void:
	for code: String in _push.keys():
		var j: Dictionary = _push[code]
		j["left"] = float(j["left"]) - delta
		var n := piece(code)
		if n == null:
			_push.erase(code)
			continue
		var total := maxf(_repo.bal("war_plot_push_s"), 0.0001)
		var t := clampf(1.0 - float(j["left"]) / total, 0.0, 1.0)
		var pos: Vector3 = (j["from"] as Vector3).lerp(j["to"], t)

func _pose(state: GameState, code: String, node: Node3D) -> void:
	var form := node.get_node_or_null("Figures/Formation")
	if form == null:
		return
	var action := WarRoom.pose_action(ArmySystem.order_of(_repo, state, code))
	var frame := _repo.bal("war_pose_frame_" + action.to_lower())
	for a: AnimationPlayer in Map3DFormation.anims_of(form):
		var clip := Map3DUnits.clip_named(a, action)
		if clip != "":
			a.play(clip)
			a.seek(a.get_animation(clip).length * frame, true)
			a.pause()


func _model_height(node: Node3D) -> float:
	var top := 0.0
	for m: MeshInstance3D in Map3DUnits.meshes(node):
		var a := m.get_aabb()
		top = maxf(top, a.end.y)
	return top
```

```glsl
// scenes/war_room/ink_drawing.gdshader
// The folio's figure as a fight-book drawing (owner 2026-10-01, spec §4): no
// colour, sepia hatching by the light on vellum — dense where the light falls
// away, none where it falls full. Screen-space strokes, so it reads as drawn.
shader_type spatial;
render_mode unshaded, cull_back;

uniform vec4 ink : source_color = vec4(0.169, 0.129, 0.094, 1.0);
uniform vec4 paper : source_color = vec4(0.914, 0.863, 0.753, 1.0);
uniform vec3 light_dir = vec3(-0.5, 0.7, 0.5);
uniform float stroke_px = 5.0;

void fragment() {
	vec3 n = normalize((INV_VIEW_MATRIX * vec4(NORMAL, 0.0)).xyz);
	float lit = clamp(dot(n, normalize(light_dir)), 0.0, 1.0);
	vec2 p = FRAGCOORD.xy / stroke_px;
	float h1 = step(0.5, fract(p.x + p.y));
	float h2 = step(0.5, fract(p.x - p.y));
	float dark = 0.0;
	if (lit < 0.55) dark = h1;
	if (lit < 0.25) dark = max(dark, h2);
	ALBEDO = mix(paper.rgb, ink.rgb, dark * 0.85);
}
```

```gdscript
# scripts/war_room/war_explode.gd
class_name WarExplode
extends RefCounted
## The folio's exploded view (spec 2026-10-01-war-room-design §4): each part of
## an arm's STATIC parts model flies straight out from the figure's centre.
## The game's skinned mesh cannot be taken apart at runtime (a shader has no
## bone index), so the parts are their own file, exported from Blender.

static func parts_path(arm: String) -> String:
	var a := "infantry" if arm == "archers" else arm
	return "res://assets/3D/units/%s/%s_parts.glb" % [a, a]


static func offsets(centres: Dictionary, centre: Vector3, distance: float) -> Dictionary:
	var out: Dictionary = {}
	for name: String in centres:
		var d: Vector3 = (centres[name] as Vector3) - centre
		out[name] = (d.normalized() if d.length() > 0.0001 else Vector3.UP) * distance
	return out
```

```gdscript
var _part_home: Dictionary = {}   # object name -> its assembled position

func show_parts(repo: DataRepository, arm: String) -> bool:
	var path := WarExplode.parts_path(arm)
	if not ResourceLoader.exists(path):
		return false
	if _parts != null:
		_viewport.remove_child(_parts)
		_parts.queue_free()
	_parts = (load(path) as PackedScene).instantiate() as Node3D
	_viewport.add_child(_parts)
	if _model != null:
		_model.visible = false
	var mat := INK.duplicate(true) as ShaderMaterial
	mat.set_shader_parameter("ink", repo.war_palette["ink"])
	mat.set_shader_parameter("paper", repo.war_palette["paper"])
	var centres: Dictionary = {}
	var all := AABB()
	var first := true
	for m: MeshInstance3D in Map3DUnits.meshes(_parts):
		m.material_override = mat
		var a := m.transform * m.get_aabb()
		all = a if first else all.merge(a)
		first = false
		centres[String(m.name)] = a.get_center()
		_part_home[String(m.name)] = m.position
	_part_off = WarExplode.offsets(centres, all.get_center(), repo.bal("war_explode_m"))
	for k: Dictionary in WarFolio.kit_of(repo, arm):
		var node := _parts.find_child(String(k["part"]), true, false) as Node3D
		if node == null:
			continue
		var tag := Label3D.new()
		tag.text = String(k["label"])
		tag.font_size = 22
		tag.pixel_size = 0.004
		tag.billboard = BaseMaterial3D.BILLBOARD_ENABLED
		tag.modulate = repo.war_palette["ink"]
		tag.position = (centres.get(String(k["part"]), Vector3.ZERO) as Vector3) + (_part_off.get(String(k["part"]), Vector3.ZERO) as Vector3) * 1.25
		_parts.add_child(tag)
	explode(0.0)
	return true


func explode(t: float) -> void:
	if _parts == null:
		return
	for m: MeshInstance3D in Map3DUnits.meshes(_parts):
		var name := String(m.name)
		m.position = (_part_home.get(name, Vector3.ZERO) as Vector3) + (_part_off.get(name, Vector3.ZERO) as Vector3) * t


func show_drill() -> void:
	if _parts != null:
		_viewport.remove_child(_parts)
		_parts.queue_free()
		_parts = null
	if _model != null:
		_model.visible = true
```
