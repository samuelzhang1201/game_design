# LEDGER L0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the RELATIONSHIP tab with the LEDGER — a 3D orrery of the realm's ontology (spheres for objects, threads for links on three layers KNOW / PEOPLE / THINGS) that reads the live engine through `Intel`, moves the web of the court in as its Court lens, and issues real orders from a right click.

**Architecture:** The ontology is CSV rows (`data/ledger_*.csv`). A pure engine layer (`Ledger`, `LedgerResolvers`, `LedgerCards` in `scripts/engine/`) turns those rows plus the live `GameState` into a deterministic snapshot `{nodes, links, loops}`, every figure passed through `Intel`. A 3D view (`scripts/ledger3d/`, scene `scenes/ledger/ledger_view.tscn`) draws a snapshot and only emits signals; `LedgerScreen` (`scripts/ui/`) is the one piece that touches `Game`, fills the left column and runs orders through `Game.try_execute`.

**Tech Stack:** Godot 4.7, typed GDScript, Forward+, GUT 9.4.

**Spec:** `docs/superpowers/specs/2026-09-30-ledger-ontology-design.md` (L0 = §6, §7, §9; the charter §2–§5 is data here).

## Global Constraints

- Typed GDScript everywhere: type hints on vars, params, returns. `snake_case` files/functions, `PascalCase` classes, past-tense signals.
- **Design values live in CSVs, never in scripts** — every look number in `balance.csv` `ledger_*`, every colour in `data/ledger_palette.csv`, every type / link / action / loop / lens a row.
- **Invariant 1**: an order is always a real `action_code` that exists in `Game.data.actions` and has an `order_costs.csv` row (invariant 8). Never invent one; if a row this plan names lacks a cost row, STOP and report — do not add a cost.
- **Invariant 2**: `Ledger*` engine code draws no RNG, reads no clock, writes no state. The layout's force pass is deterministic (fixed iterations, sorted ids).
- **Invariant 3**: `scripts/engine/ledger*.gd` are `RefCounted`, no Node. `tests/engine/test_engine_isolation.gd` already forbids `Game.` and any `scripts/ui` / `scripts/llm` class_name in `scripts/engine/`.
- **Nothing under `scripts/ledger3d/` may contain the substring `Game.`** (comments included — the scan is a plain substring match, as for `scripts/map3d/`).
- **No numeric credibility anywhere in the LEDGER's UI** (intelligence ruling): credibility is ink density, age is yellowing.
- **The land is never hidden** does not apply here, but the charter's rule 5 does: every TYPE is always drawn; only values and instance links are blurred.
- **Never name Palantir or Gotham** in code, data, UI text or commit messages.
- The spec's `group` column is the `layer` column (one column, values `know` / `people` / `things`); the spec's `intel_subject` column is carried per link by the resolver (`subj`), not a CSV column. Task 11 records both in the spec.

## Review Focus

1. **A focus that vanishes while the LEDGER is open** (a courier delivered, a missive capped out, a character gone) — the next refresh must fall back to the type level (`focus_lost`), never crash or draw a dangling thread. Pinned in Task 4 (`test_a_vanished_focus_falls_back_to_the_type_level`).
2. **A huge ego network** (a house holding hundreds of manors) — each link type shows at most `ledger_instance_cap` neighbours plus one "+N more" sphere. Pinned in Task 4 (`test_the_cap_folds_the_rest_into_one_more_sphere`).
3. **A fresh campaign with nothing in flight** (no missives, no couriers) and **type-level self links** (the court's character→character types) — no zero-length thread reaches the view, and the picking maths survive one anyway. Pinned in Task 4 (`test_no_link_joins_a_sphere_to_itself`, `test_a_fresh_reign_with_no_letters_still_draws`) and Task 5 (`test_a_zero_length_thread_is_a_point`).
4. **DEV MODE toggled while open** — a foreign manor's yield turns from words to a number on the next snapshot, and back. Pinned in Task 4 (`test_the_intel_gate_blurs_what_the_crown_does_not_control`).
5. **The window resized, or a HiDPI display, while open** — the SubViewport follows the control's size × the window scale, and every pick multiplies the pointer by the same scale. Pinned in Task 5 (`test_screen_to_viewport_uses_the_window_scale`) and Task 6 (the view calls it for every ray).

```gdscript
# scripts/engine/ledger_resolvers.gd
class_name LedgerResolvers
extends RefCounted
## The LEDGER's readers (spec 2026-09-30-ledger-ontology-design §7.2): one
## per live link type of data/ledger_link_types.csv. Each reads the real
## systems and returns the TRUTH; Ledger turns it into belief through Intel.
## They never write state and never draw RNG.
##
## A returned link: {from, to, flow, subj, key}
##   from / to - node ids: "type:<type_id>" at the type level, "<type>:<id>"
##               for an instance
##   flow      - whole units a month, or a count; -1 for no magnitude (a
##               lever, or a tie that is only there or not)
##   subj      - the Intel subject that gates it ({} = the crown's own
##               records, always "full")
##   key       - the fact key Intel words it by
##
## focus {} is the type level (one link between the two type spheres, the
## crown's own figures); {"id": node id} the links touching that instance;
## {"all": true} every instance link (the court lens).

const NAMES := ["works", "part_of", "yields_civil", "yields_strategic", "taxed", "trade_gold",
	"rations", "stands_on", "holds", "member", "sits", "based_in", "carries", "spies_on",
	"describes", "court_relations"]
const INSTANCE_LISTS := ["peasants", "manors", "provinces", "regiments", "characters", "houses",
	"seats", "reports", "couriers"]
const REPORT_KINDS := {"describes_province": "province", "describes_manor": "manor",
	"describes_regiment": "regiment", "describes_town": "burg"}


static func has(name: String) -> bool:
	return name in NAMES


static func has_instances(name: String) -> bool:
	return name in INSTANCE_LISTS


static func run(row: Dictionary, repo: DataRepository, state: GameState, focus: Dictionary) -> Array:
	var from_t := String(row["from_type"])
	var to_t := String(row["to_type"])
	var id := String(focus.get("id", ""))
	var all := bool(focus.get("all", false))
	match String(row["resolver"]):
		"works":
			return _works(repo, state, id)
		"part_of":
			return _part_of(repo, state, id)
		"yields_civil":
			return _yields(repo, state, id, "civil", to_t)
		"yields_strategic":
			return _yields(repo, state, id, "strategic", to_t)
		"taxed":
			return _yields(repo, state, id, "tax", to_t)
		"trade_gold":
			return [_type_link(from_t, to_t, -1, "gold")] if id == "" and not all else []
		"rations":
			return [_type_link(from_t, to_t, TickEngine.ration_of(repo, state), "gold")] \
				if id == "" and not all else []
		"stands_on":
			return _stands_on(repo, state, id)
		"holds":
			return _holds(repo, state, id)
		"member":
			return _member(state, id)
		"sits":
			return _sits(state, id)
		"based_in":
			return _based_in(repo, state, id)
		"carries":
			return _couriers(repo, state, id, false)
		"spies_on":
			return _couriers(repo, state, id, true)
		"describes":
			return _describes(state, id, String(row["link_id"]), to_t)
		"court_relations":
			return _relations(state, id, all, String(row["link_id"]))
	return []


# --- the links -------------------------------------------------------------

static func _type_link(from_t: String, to_t: String, flow: int, key: String) -> Dictionary:
	return {"from": "type:" + from_t, "to": "type:" + to_t, "flow": flow, "subj": {}, "key": key}


static func _link(from_id: String, to_id: String, flow: int, key: String,
		subj: Dictionary = {}) -> Dictionary:
	return {"from": from_id, "to": to_id, "flow": flow, "subj": subj, "key": key}


static func _rest(id: String) -> String:
	return id.substr(id.get_slice(":", 0).length() + 1)


static func _manor_subj(repo: DataRepository, cell: int) -> Dictionary:
	return MissiveLog.subject("manor", MapManors.code_of(repo, cell), cell,
		MapTerrain.cell_center(repo, repo.cells[cell]))


static func _province_subj(repo: DataRepository, code: String) -> Dictionary:
	var prov: Dictionary = repo.provinces.get(code, {})
	return MissiveLog.subject("province", code, -1,
		Vector2(float(prov.get("center_x", 0.0)), float(prov.get("center_y", 0.0))))


## The crown's own intake a month — what reaches its two purses.
static func _intake(repo: DataRepository, state: GameState) -> Dictionary:
	var p := RealmEconomy.purses(repo, state)
	var lord: Dictionary = p["lord"]
	var share: Dictionary = p["realm_share"]
	return {"tax": int(lord["tax"]) + int(share["tax"]),
		"strategic": int(lord["strategic"]) + int(share["strategic"]),
		"civil": int(lord["civil"]) + int(share["civil"])}

	var out: Array = []
	for code: String in MapManors.controlled_provinces(repo, state):
		out.append_array(MapManors.manors_of_province(repo, code, state))
	return out


static func _works(repo: DataRepository, state: GameState, id: String) -> Array:
	if id == "":
		return [_type_link("peasants", "manor", TickEngine.court_people(repo, state), "people")]
	if id.begins_with("peasants:"):
		var out: Array = []
		for cell: int in MapManors.manors_of_province(repo, _rest(id), state):
			var line := RealmEconomy.line_of(repo, state, cell)
			out.append(_link(id, "manor:%d" % cell, int(line["people"]), "people", _manor_subj(repo, cell)))
		return out
	if id.begins_with("manor:"):
		var cell := int(_rest(id))
		var line := RealmEconomy.line_of(repo, state, cell)
		return [_link("peasants:" + MapManors.province_of(repo, cell, state), id,
			int(line["people"]), "people", _manor_subj(repo, cell))]
	return []


static func _part_of(repo: DataRepository, state: GameState, id: String) -> Array:
	if id == "":
		return [_type_link("manor", "province", _controlled_manors(repo, state).size(), "count")]
	if id.begins_with("manor:"):
		var cell := int(_rest(id))

			_manor_subj(repo, cell))]
	if id.begins_with("province:"):
		var out: Array = []
		for cell: int in MapManors.manors_of_province(repo, _rest(id), state):
			out.append(_link("manor:%d" % cell, id, -1, "count", _manor_subj(repo, cell)))
		return out
	return []


static func _yields(repo: DataRepository, state: GameState, id: String, key: String,
		to_t: String) -> Array:
	if id == "":
		return [_type_link("manor", to_t, int(_intake(repo, state)[key]), "gold")]
	if id.begins_with("manor:"):
		var cell := int(_rest(id))
		var line := RealmEconomy.line_of(repo, state, cell)
		return [_link(id, "type:" + to_t, int(line[key]), "gold", _manor_subj(repo, cell))]
	return []


static func _stands_on(repo: DataRepository, state: GameState, id: String) -> Array:
	if id == "":
		var n := 0
		var mine := MapManors.controlled_provinces(repo, state)
		for key: String in state.manor_buildings:
			if MapManors.province_of(repo, int(key), state) in mine:
				n += (state.manor_buildings[key] as Array).size()
		return [_type_link("building", "manor", n, "count")]
	if id.begins_with("manor:"):
		var cell := int(_rest(id))
		var out: Array = []
		for code: String in state.manor_buildings.get(str(cell), []):
			out.append(_link("building:%d:%s" % [cell, code], id, -1, "count", _manor_subj(repo, cell)))
		return out
	if id.begins_with("building:"):
		var cell := int(_rest(id).get_slice(":", 0))
		return [_link(id, "manor:%d" % cell, -1, "count", _manor_subj(repo, cell))]
	return []


static func _holds(repo: DataRepository, state: GameState, id: String) -> Array:
	if id == "":
		return [_type_link("house", "manor", _controlled_manors(repo, state).size(), "count")]
	if id.begins_with("house:"):
		var out: Array = []
		for cell: int in MapManors.manors_of_house(repo, state, _rest(id)):

	if id.begins_with("manor:"):
		var cell := int(_rest(id))
		var owner := String(MapManors.owner_of(repo, state, cell))
		return [] if owner == "" else [_link("house:" + owner, id, -1, "count", _manor_subj(repo, cell))]
	return []


static func _member(state: GameState, id: String) -> Array:
	if id == "":
		var n := 0
		for cid: String in state.characters:
			if (state.characters[cid] as Character).family_name != "":

		return [_type_link("character", "house", n, "count")]
	if id.begins_with("character:"):

	if id.begins_with("house:"):
		var out: Array = []
		var ids: Array = state.characters.keys()
		ids.sort()
		for cid: String in ids:
			if (state.characters[cid] as Character).family_name == _rest(id):
				out.append(_link("character:" + cid, id, -1, "count"))
		return out
	return []

	if id == "":
		return [_type_link("character", "seat", state.council.size(), "count")]
	if id.begins_with("character:"):
		var out: Array = []
		for seat: String in state.council:
			if String(state.council[seat]) == _rest(id):
				out.append(_link(id, "seat:" + seat, -1, "count"))
		return out
	if id.begins_with("seat:"):
		var cid := String(state.council.get(_rest(id), ""))
		return [] if cid == "" else [_link("character:" + cid, id, -1, "count")]
	return []


## The province a regiment has REACHED (ArmySystem.position_of), not the one
## the pack seeded it in.
static func _province_now(repo: DataRepository, state: GameState, reg: Dictionary) -> String:
	var at := ArmySystem.position_of(repo, state, reg)
	return Intel.province_of(repo, state, MissiveLog.subject("point", "", -1, at))


static func _based_in(repo: DataRepository, state: GameState, id: String) -> Array:
	var regs := MapObjects.regiments_of(repo, repo.resolve_realm("player_realm"))
	if id == "":
		return [_type_link("regiment", "province", regs.size(), "count")]
	var out: Array = []
	for reg: Dictionary in regs:
		var code := String(reg["regiment_code"])
		var here := _province_now(repo, state, reg)
		if here == "":
			continue
		if id == "regiment:" + code or id == "province:" + here:
			out.append(_link("regiment:" + code, "province:" + here, ArmySystem.headcount(repo, reg), "heads",
				MissiveLog.subject("regiment", code, -1, ArmySystem.position_of(repo, state, reg))))
	return out


static func _aim_province(repo: DataRepository, state: GameState, c: Dictionary) -> String:
	var px := ArmySystem.metres_to_pack(repo, Vector2i(int(c["aim_x_m"]), int(c["aim_y_m"])))
	return Intel.province_of(repo, state, MissiveLog.subject("point", "", -1, px))


static func _couriers(repo: DataRepository, state: GameState, id: String, spy: bool) -> Array:
	var mine: Array = []
	for c: Dictionary in state.couriers:
		if (String(c["kind"]) == CourierSystem.SPY) == spy:
			mine.append(c)
	if id == "":
		return [_type_link("courier", "province" if spy else "regiment", mine.size(), "count")]
	var out: Array = []
	for c: Dictionary in mine:
		var cid := "courier:%d" % int(c["id"])
		var to := ("province:" + _aim_province(repo, state, c)) if spy else ("regiment:" + String(c["target"]))
		if to.ends_with(":"):
			continue
		if id == cid or id == to:
			out.append(_link(cid, to, -1, "count"))
	return out


static func _subject_node(to_t: String, subj: Dictionary) -> String:
	match to_t:
		"manor":
			return "manor:%d" % int(subj.get("cell", -1))
		"town":
			return "town:" + String(subj.get("code", ""))
	return to_t + ":" + String(subj.get("code", ""))


static func _describes(state: GameState, id: String, link_id: String, to_t: String) -> Array:
	var kind := String(REPORT_KINDS.get(link_id, ""))
	var about: Array = []
	for i in range(state.missives.size() - 1, -1, -1):  # newest first
		var m: Dictionary = state.missives[i]
		if String((m["subject"] as Dictionary).get("kind", "")) == kind:
			about.append(m)
	if id == "":
		return [_type_link("report", to_t, about.size(), "count")]
	var out: Array = []
	for m: Dictionary in about:
		var rid := "report:%d" % int(m["id"])
		var node := _subject_node(to_t, m["subject"])
		if id == rid or id == node:
			out.append(_link(rid, node, -1, "count"))
	return out


static func _relations(state: GameState, id: String, all: bool, rel_type: String) -> Array:
	if id == "" and not all:
		return []  # character to character: an instance tie only
	var out: Array = []
	for e: Dictionary in state.relationships:
		if String(e["type"]) != rel_type:
			continue
		var from := "character:" + String(e["from"])
		var to := "character:" + String(e["to"])
		if all or id == from or id == to:
			var l := _link(from, to, absi(int(e["sentiment"])), "sentiment")
			l["sentiment"] = int(e["sentiment"])
			out.append(l)
	return out

static func instances(name: String, repo: DataRepository, state: GameState) -> Array:

		"manors":

					"strain": int(RealmEconomy.line_of(repo, state, cell)["people"])})
		"provinces":
			for code: String in MapOwnership.provinces_of(repo, state, realm):
				out.append({"id": "province:" + code, "strain": 2 - int(state.wealth_tiers.get(code, 1))})
		"regiments":
			for reg: Dictionary in MapObjects.regiments_of(repo, realm):
				var code := String(reg["regiment_code"])
				out.append({"id": "regiment:" + code, "strain": 1000 - ArmySystem.bars_of(repo, state, code).x})
		"characters":
			for cid: String in state.characters:
				out.append({"id": "character:" + cid, "strain": -(state.characters[cid] as Character).opinion})
		"houses":
			var seen := {}
			for code: String in MapOwnership.provinces_of(repo, state, realm):
				var fam := MapObjects.house_name_of(repo, code)
				if fam != "" and not seen.has(fam):
					seen[fam] = true
					out.append({"id": "house:" + fam, "strain": 0})
		"seats":
			for seat: String in repo.seats:
				out.append({"id": "seat:" + seat, "strain": 0 if state.council.has(seat) else 1})
		"reports":
			for m: Dictionary in state.missives:
				out.append({"id": "report:%d" % int(m["id"]), "strain": int(m["day"])})
		"couriers":
			for c: Dictionary in state.couriers:
				out.append({"id": "courier:%d" % int(c["id"]), "strain": int(c.get("days", 0))})
	for row: Dictionary in out:
		row["label"] = label_of(repo, state, String(row["id"]))
	out.sort_custom(func(a: Dictionary, b: Dictionary) -> bool:
		if int(a["strain"]) != int(b["strain"]):
			return int(a["strain"]) > int(b["strain"])
		return String(a["label"]) < String(b["label"]))
	return out


## A node's name, or "" when what it names no longer exists.
static func label_of(repo: DataRepository, state: GameState, id: String) -> String:
	var kind := id.get_slice(":", 0)
	var rest := _rest(id)
	match kind:
```

```gdscript
# scripts/engine/ledger.gd
class_name Ledger
extends RefCounted
## The LEDGER — the realm's ontology (spec 2026-09-30-ledger-ontology-design).
## Rows of data/ledger_*.csv checked as a schema, and (Task 4) turned with
## the live state into the picture the LEDGER screen draws. It reads, never
## writes; it draws no RNG and reads no clock.

const LAYERS := ["things", "people", "know"]   # bottom to top
const STATUSES := ["live", "planned"]


static func type_row(repo: DataRepository, type_id: String) -> Dictionary:
	for r: Dictionary in repo.ledger_types:
		if String(r["type_id"]) == type_id:
			return r
	return {}


static func link_row(repo: DataRepository, link_id: String) -> Dictionary:
	for r: Dictionary in repo.ledger_links:
		if String(r["link_id"]) == link_id:
			return r
	return {}


static func type_of(node_id: String) -> String:
	if node_id.contains("|"):
		return ""
	if node_id.begins_with("type:"):
		return node_id.substr(5)
	return node_id.get_slice(":", 0)


static func in_lens(row: Dictionary, lens: String) -> bool:
	return lens in String(row["lenses"]).split("|", false)


static func validate(repo: DataRepository) -> Array[String]:
	var errors: Array[String] = []
	var lenses := {}
	for l: Dictionary in repo.ledger_lenses:
		lenses[String(l["lens"])] = l
	var types := {}
	for r: Dictionary in repo.ledger_types:
		var id := String(r["type_id"])
		types[id] = r
		if not String(r["layer"]) in LAYERS:
			errors.append("%s: unknown layer %s" % [id, r["layer"]])
		_check_status(errors, id, r)
		_check_lenses(errors, id, r, lenses)
		if String(r["instances"]) != "" and not LedgerResolvers.has_instances(String(r["instances"])):
			errors.append("%s: unknown instance list %s" % [id, r["instances"]])
	for lens: String in lenses:
		var it := String(lenses[lens]["instance_type"])
		if it != "" and not types.has(it):
			errors.append("lens %s: unknown instance type %s" % [lens, it])
	var links := {}
	for r: Dictionary in repo.ledger_links:
		var id := String(r["link_id"])
		links[id] = r
		_check_status(errors, id, r)
		_check_lenses(errors, id, r, lenses)
		for end in ["from_type", "to_type"]:
			if not types.has(String(r[end])):
				errors.append("%s: unknown type %s" % [id, r[end]])
		if String(r["status"]) == "live":
			if not LedgerResolvers.has(String(r["resolver"])):
				errors.append("%s: live without a reader" % id)
			for end in ["from_type", "to_type"]:
				if String((types.get(String(r[end]), {}) as Dictionary).get("status", "")) == "planned":
					errors.append("%s: live on a planned type" % id)
		var seat := String(r["governor_seat"])
		if seat != "" and not repo.seats.has(seat):
			errors.append("%s: unknown seat %s" % [id, seat])
		if not String(r["governor_kind"]) in ["", "seat", "faction"]:
			errors.append("%s: unknown governor kind %s" % [id, r["governor_kind"]])
	for a: Dictionary in repo.ledger_actions:
		var code := String(a["action_code"])
		if not types.has(String(a["target"])) and not links.has(String(a["target"])):
			errors.append("%s: unknown target %s" % [code, a["target"]])
		if not repo.actions.has(code):
			errors.append("%s: unknown action" % code)
		elif not repo.order_costs.has(code):
			errors.append("%s: no order_costs row (invariant 8)" % code)
	for lp: Dictionary in repo.ledger_loops:
		for l: String in String(lp["links"]).split("|", false):
			if not links.has(l):
				errors.append("loop %s: unknown link %s" % [lp["loop_id"], l])
		if not String(lp["kind"]) in ["virtuous", "vicious"]:
			errors.append("loop %s: unknown kind %s" % [lp["loop_id"], lp["kind"]])
	return errors


static func _check_status(errors: Array[String], id: String, r: Dictionary) -> void:
	if not String(r["status"]) in STATUSES:
		errors.append("%s: unknown status %s" % [id, r["status"]])
	if String(r["status"]) == "planned" and String(r["milestone"]) == "":
		errors.append("%s: planned without a milestone" % id)


static func _check_lenses(errors: Array[String], id: String, r: Dictionary, lenses: Dictionary) -> void:
	for l: String in String(r["lenses"]).split("|", false):
		if not lenses.has(l):
			errors.append("%s: unknown lens %s" % [id, l])
```

```gdscript
# --- the picture -----------------------------------------------------------

## The picture of one lens (spec §6-§7). focus is {} (the type level, or the
## lens's own instances for a lens with an instance_type: the court) or
## {"id": node id} (that instance's ego network). A focus that no longer
## exists falls back to the type level with focus_lost set.
static func snapshot(repo: DataRepository, state: GameState, lens: String, focus: Dictionary) -> Dictionary:
	var out := {"lens": lens, "focus_id": "", "focus_lost": false, "day": state.absolute_day(),
		"nodes": [], "links": [], "loops": []}
	var focus_id := String(focus.get("id", ""))
	if focus_id != "" and not exists(repo, state, focus_id):
		out["focus_lost"] = true
		focus_id = ""
	var inst_type := ""
	for l: Dictionary in repo.ledger_lenses:
		if String(l["lens"]) == lens:
			inst_type = String(l["instance_type"])
	if focus_id != "":
		out["focus_id"] = focus_id
		_ego(repo, state, lens, focus_id, out)
	elif inst_type != "":
		_all_instances(repo, state, lens, inst_type, out)
	else:
		_type_level(repo, state, lens, out)
	_loops(repo, state, out)
	return out


static func exists(repo: DataRepository, state: GameState, node_id: String) -> bool:
	if node_id.begins_with("type:"):
		return not type_row(repo, node_id.substr(5)).is_empty()
	return LedgerResolvers.label_of(repo, state, node_id) != ""


static func _type_level(repo: DataRepository, state: GameState, lens: String, out: Dictionary) -> void:
	var shown := {}
	for r: Dictionary in repo.ledger_types:
		if not in_lens(r, lens):
			continue
		shown[String(r["type_id"])] = true
		var node := _node(repo, state, "type:" + String(r["type_id"]))
		node["x"] = float(r["x"])
		node["z"] = float(r["z"])
		out["nodes"].append(node)
	for r: Dictionary in repo.ledger_links:
		if not in_lens(r, lens) or not shown.has(String(r["from_type"])) or not shown.has(String(r["to_type"])):
			continue
		if String(r["from_type"]) == String(r["to_type"]):
			continue  # a tie between two of one type is drawn between instances only
		if String(r["status"]) == "planned":
			out["links"].append(_planned(state, r))
			continue
		for t: Dictionary in LedgerResolvers.run(r, repo, state, {}):
			out["links"].append(_believed(repo, state, r, t))


static func _all_instances(repo: DataRepository, state: GameState, lens: String, inst_type: String,
		out: Dictionary) -> void:
	var list := String(type_row(repo, inst_type).get("instances", ""))
	for row: Dictionary in LedgerResolvers.instances(list, repo, state):
		out["nodes"].append(_node(repo, state, String(row["id"])))
	for r: Dictionary in repo.ledger_links:
		if String(r["status"]) != "live" or not in_lens(r, lens):
			continue
		if String(r["from_type"]) != inst_type or String(r["to_type"]) != inst_type:
			continue
		for t: Dictionary in LedgerResolvers.run(r, repo, state, {"all": true}):
			out["links"].append(_believed(repo, state, r, t))


static func _ego(repo: DataRepository, state: GameState, lens: String, focus_id: String, out: Dictionary) -> void:
	var ftype := type_of(focus_id)
	var seen := {focus_id: true}
	out["nodes"].append(_node(repo, state, focus_id))
	var cap := int(repo.bal("ledger_instance_cap"))
	for r: Dictionary in repo.ledger_links:
		if String(r["status"]) != "live" or not in_lens(r, lens):
			continue
		if String(r["from_type"]) != ftype and String(r["to_type"]) != ftype:
			continue
		var found: Array = LedgerResolvers.run(r, repo, state, {"id": focus_id}).filter(
			func(t: Dictionary) -> bool: return String(t["from"]) == focus_id or String(t["to"]) == focus_id)
		for i in found.size():
			var t: Dictionary = found[i]
			var outward := String(t["from"]) == focus_id
			if i == cap:
				var more := "more:%s:%d" % [r["link_id"], found.size() - cap]
				var other_type := String(r["to_type"]) if outward else String(r["from_type"])
				out["nodes"].append({"id": more, "type": "more", "label": LedgerResolvers.label_of(repo, state, more),
					"layer": String(type_row(repo, other_type)["layer"]), "status": "live", "milestone": "",
					"instance": true})
				var folded := {"from": focus_id if outward else more, "to": more if outward else focus_id,
					"flow": -1, "subj": {}, "key": "count"}
				out["links"].append(_believed(repo, state, r, folded))
				break
			var other := String(t["to"]) if outward else String(t["from"])
			if not seen.has(other):
				seen[other] = true
				out["nodes"].append(_node(repo, state, other))
			out["links"].append(_believed(repo, state, r, t))

	var t := type_of(id)
	var row := type_row(repo, t)
	return {"id": id, "type": t, "label": LedgerResolvers.label_of(repo, state, id),

		"milestone": String(row.get("milestone", "")), "instance": not id.begins_with("type:")}
```

```gdscript
static func entry(repo: DataRepository, state: GameState, node_id: String, snap: Dictionary) -> Dictionary:
	var kind := node_id.get_slice(":", 0)
	var rest := node_id.substr(kind.length() + 1)
	match kind:
		"manor":
			return {"obj": {"kind": "manor", "cell": int(rest)}}
		"town":
			return {"obj": {"kind": "burg", "code": rest}}
		"regiment":
			return {"obj": {"kind": "army", "code": rest}}
		"courier":
			return {"obj": {"kind": "courier", "id": int(rest)}}

	var t := Ledger.type_of(node_id)
	var row := Ledger.type_row(repo, t)
	if String(row.get("status", "")) == "planned":
		lines.append("Not yet built (%s). %s" % [row["milestone"], String(row.get("notes", ""))])
	for l: Dictionary in snap.get("links", []):
		if String(l["from"]) != node_id and String(l["to"]) != node_id:
			continue

	return {"title": LedgerResolvers.label_of(repo, state, node_id), "lines": lines}


static func thread_entry(repo: DataRepository, state: GameState, link: Dictionary) -> Dictionary:
	var title := "%s %s %s" % [LedgerResolvers.label_of(repo, state, String(link["from"])), link["verb"],
		LedgerResolvers.label_of(repo, state, String(link["to"]))]
	var lines: Array[String] = []
	if String(link["status"]) == "planned":
		lines.append("Not yet built: " + String(link["planned_note"]))
	for acc: Dictionary in link["accounts"]:
		lines.append(_account(acc, state.absolute_day()))
	if String(link["governor"]) != "":
		var c: Character = state.characters.get(String(link["governor"]))
		if c != null:
			lines.append("Governed by " + c.display_name)
	return {"title": title, "lines": lines}


static func subject_of(repo: DataRepository, state: GameState, node_id: String) -> Dictionary:
	var kind := node_id.get_slice(":", 0)
	var rest := node_id.substr(kind.length() + 1)
	match kind:
		"manor":
			var cell := int(rest)
			return MissiveLog.subject("manor", MapManors.code_of(repo, cell), cell,
				MapTerrain.cell_center(repo, repo.cells[cell]))
		"province", "peasants":
			var p: Dictionary = repo.provinces.get(rest, {})
			return {} if p.is_empty() else MissiveLog.subject("province", rest, -1,
				Vector2(float(p["center_x"]), float(p["center_y"])))
		"town":
			var b: Dictionary = repo.burgs.get(rest, {})
			return {} if b.is_empty() else MissiveLog.subject("burg", rest, -1, Vector2(float(b["x"]), float(b["y"])))
		"regiment":
			var reg := ArmySystem.regiment(repo, rest)
			return {} if reg.is_empty() else MissiveLog.subject("regiment", rest, -1,
				ArmySystem.position_of(repo, state, reg))
	return {}


static func _line(repo: DataRepository, state: GameState, l: Dictionary, node_id: String, today: int) -> String:
	var outward := String(l["from"]) == node_id
	var other := LedgerResolvers.label_of(repo, state, String(l["to"] if outward else l["from"]))
	var head := ("%s %s" % [l["verb"], other]) if outward else ("%s: %s" % [other, l["verb"]])
	if String(l["status"]) == "planned":
		return "%s — not yet built" % head
	var accs: Array = l["accounts"]
	return head if accs.is_empty() else "%s — %s" % [head, _account(accs[0], today)]

	var age := today - int(acc["day"])
	var when := "" if age <= 0 else (", %d days ago" % age if age != 1 else ", yesterday")
	if text == "":
		return source + when
	return "%s · %s%s" % [text, source, when]
```

```gdscript
# scripts/ledger3d/ledger_orbit.gd
class_name LedgerOrbit
extends RefCounted
## The LEDGER's camera as numbers (spec 2026-09-30 §6.2): it orbits a target
## at a distance, a yaw and a pitch. Turning, panning and zooming change only
## these; the view turns them into the Camera3D's transform.

var target := Vector3.ZERO
var distance := 30.0
var yaw := 0.0      # degrees, 0 looks along -Z
var pitch := -24.0  # degrees, negative looks down from above
var min_distance := 8.0
var max_distance := 90.0


func pose() -> Transform3D:
	var back := Vector3(0, 0, 1).rotated(Vector3.RIGHT, deg_to_rad(pitch)).rotated(Vector3.UP, deg_to_rad(yaw))
	var eye := target + back * distance
	return Transform3D(Basis.looking_at(target - eye, Vector3.UP), eye)


func turn(dx_px: float, dy_px: float, deg_per_px: float) -> void:
	yaw -= dx_px * deg_per_px
	pitch = clampf(pitch - dy_px * deg_per_px, -85.0, -5.0)


func zoom(factor: float) -> void:
	distance = clampf(distance * factor, min_distance, max_distance)


func pan(screen_delta: Vector2, m_per_px: float) -> void:
	var b := pose().basis
	target += (-b.x * screen_delta.x + b.y * screen_delta.y) * m_per_px


func metres_per_px(fov_deg: float, view_h_px: float) -> float:
	return 2.0 * distance * tan(deg_to_rad(fov_deg) * 0.5) / maxf(view_h_px, 1.0)
```

```gdscript
## threads as segments. Spheres beat threads.


## The nearest t >= 0 at which a ray (d normalised) meets a sphere, or -1.
static func ray_sphere(o: Vector3, d: Vector3, c: Vector3, r: float) -> float:
	var oc := o - c
	var b := oc.dot(d)
	var disc := b * b - (oc.dot(oc) - r * r)
	if disc < 0.0:
		return -1.0
	var s := sqrt(disc)
	var t := -b - s
	if t < 0.0:
		t = -b + s
	return t if t >= 0.0 else -1.0


## The closest approach of a ray to a segment: Vector2(distance, t along the
## ray). A zero-length segment is a point.
static func ray_segment(o: Vector3, d: Vector3, a: Vector3, b: Vector3) -> Vector2:
	var u := b - a
	var c := u.dot(u)
	var w := o - a
	var dd := d.dot(w)
	if c < 1e-9:
		var t0 := maxf((a - o).dot(d), 0.0)
		return Vector2((o + d * t0).distance_to(a), t0)
	var bb := d.dot(u)
	var e := u.dot(w)
	var denom := c - bb * bb
	var tu := clampf(e / c if denom < 1e-9 else (e - bb * dd) / denom, 0.0, 1.0)
	var s := maxf(bb * tu - dd, 0.0)
	return Vector2((o + d * s).distance_to(a + u * tu), s)


static func pick(o: Vector3, d: Vector3, spheres: Array, threads: Array) -> Dictionary:
	var best := INF
	var hit := {}
	for sp: Dictionary in spheres:
		var t := ray_sphere(o, d, sp["pos"], float(sp["radius"]))
		if t >= 0.0 and t < best:
			best = t
			hit = {"kind": "sphere", "id": String(sp["id"])}
	if not hit.is_empty():
		return hit
	for th: Dictionary in threads:
		var q := ray_segment(o, d, th["a"], th["b"])
		if q.x <= float(th["radius"]) and q.y < best:
			best = q.y
			hit = {"kind": "thread", "id": String(th["id"])}
	return hit


## A pointer position in the control's design px, in the SubViewport's px
## (the view renders at window resolution).
static func screen_to_viewport(pos: Vector2, scale: float) -> Vector2:
	return pos * scale
```

```gdscript
class_name LedgerLayout
extends RefCounted
## Where each sphere stands (spec 2026-09-30 §6.2). Type spheres stand at
## their hand-set places, so the type level is the same every time; the
## spheres of an ego network or of the court are laid out per layer by a
## force layout with a fixed number of passes from places set by sorted ids,
## so one snapshot always lays out the same way. The layer sets the height.


static func layer_y(repo: DataRepository, layer: String) -> float:
	return float(maxi(Ledger.LAYERS.find(layer), 0)) * repo.bal("ledger_layer_gap_m")


static func positions(repo: DataRepository, snap: Dictionary) -> Dictionary:
	var out := {}
	var by_layer := {}
	for n: Dictionary in snap["nodes"]:
		var y := layer_y(repo, String(n["layer"]))
		if n.has("x"):
			out[String(n["id"])] = Vector3(float(n["x"]), y, float(n["z"]))
		else:
			if not by_layer.has(String(n["layer"])):
				by_layer[String(n["layer"])] = []
			by_layer[String(n["layer"])].append(String(n["id"]))
	if by_layer.is_empty():
		return out
	var focus := String(snap.get("focus_id", ""))
	var side := {}   # -1 upstream of the focus (left), +1 downstream (right)
	for l: Dictionary in snap["links"]:
		if String(l["to"]) == focus:
			side[String(l["from"])] = -1.0
		elif String(l["from"]) == focus:
			side[String(l["to"])] = 1.0
	var ring := repo.bal("ledger_ego_ring_m")
	for layer: String in by_layer:
		var ids: Array = by_layer[layer]
		ids.sort()
		var y := layer_y(repo, layer)
		for i in ids.size():
			var id := String(ids[i])
			if id == focus:
				out[id] = Vector3(0.0, y, 0.0)
				continue
			var a := PI * (float(i) + 0.5) / float(ids.size())
			var x := sin(a) * ring
			if side.has(id):
				x = absf(x) * float(side[id]) + float(side[id]) * ring * 0.5
			out[id] = Vector3(x, y, cos(a) * ring)
	var repel := repo.bal("ledger_layout_repel")
	var spring := repo.bal("ledger_layout_spring")
	for _pass in int(repo.bal("ledger_layout_iterations")):
		for layer: String in by_layer:
			var ids: Array = by_layer[layer]
			for id: String in ids:
				if id == focus:
					continue
				var p: Vector3 = out[id]
				var f := Vector2.ZERO
				for other: String in ids:
					if other == id:
						continue
					var q: Vector3 = out[other]
					var dv := Vector2(p.x - q.x, p.z - q.z)
					f += dv / maxf(dv.length_squared(), 0.01) * repel
				f -= Vector2(p.x, p.z) * spring
				if side.has(id):
					f.x += float(side[id]) * spring * ring
				var step := f * 0.1
				var nx := p.x + step.x
				if side.has(id) and signf(nx) != float(side[id]):
					nx = float(side[id]) * 0.1  # a side is kept: upstream stays left
				out[id] = Vector3(nx, p.y, p.z + step.y)
	return out
```

```gdscript
class_name LedgerHud
extends Control
## The LEDGER's sphere names (spec 2026-09-30 §6.2), drawn on a 2D layer
## over the 3D view so they always face the screen, cut once per camera pose
## so no two overlap (the Map3DHud practice). The view hands it entries.

var _ink := Color.WHITE
var _halo := Color.BLACK
var _px := 14.0

	_px = px
	_ink = ink
	_halo = halo


func show_entries(entries: Array) -> void:
	_entries = cull(entries, _px)
	queue_redraw()


## Keeps entries in order, dropping any whose box overlaps one already kept.
## The box is estimated from the text length at the font size (0.55 em a
## glyph), centred on `at`, so the cull needs no Font and is testable.
static func cull(entries: Array, font_px: float) -> Array:
	var kept: Array = []
	var boxes: Array[Rect2] = []
	for e: Dictionary in entries:
		var w := float(String(e["text"]).length()) * font_px * 0.55
		var box := Rect2((e["at"] as Vector2) - Vector2(w * 0.5, font_px), Vector2(w, font_px * 1.2))
		var clear := true
		for b in boxes:
			if b.intersects(box):
				clear = false
				break
		if clear:
			boxes.append(box)
			kept.append(e)
	return kept


func _draw() -> void:
	if _font == null:
		return
	for e: Dictionary in _entries:
		var text := String(e["text"])
		var w := _font.get_string_size(text, HORIZONTAL_ALIGNMENT_LEFT, -1, int(_px)).x
		var at := (e["at"] as Vector2) - Vector2(w * 0.5, -_px * 0.35)
		draw_string_outline(_font, at, text, HORIZONTAL_ALIGNMENT_LEFT, -1, int(_px), 4, _halo)
		draw_string(_font, at, text, HORIZONTAL_ALIGNMENT_LEFT, -1, int(_px),
			_ink if bool(e["strong"]) else Color(_ink, 0.8))
```

```glsl
// scenes/ledger/thread.gdshader
// A LEDGER thread (spec 2026-09-30 §6.3): gold wire whose ink is its
// credibility, with light running from the link's source to its end at a
// speed set by its believed flow; dashed and dark when not yet built; a
// slow glow while its loop runs. Every number is a uniform set from
// data/ledger_palette.csv and balance.csv ledger_* at build time.
shader_type spatial;
render_mode unshaded, blend_mix, cull_disabled, depth_draw_opaque;

uniform vec4 color : source_color = vec4(0.88, 0.73, 0.42, 1.0);
uniform vec4 glow_color : source_color = vec4(1.0, 0.85, 0.5, 1.0);
uniform float ink = 1.0;
uniform float fade = 1.0;
uniform float speed = 0.0;
uniform float pulses = 4.0;
uniform float dashed = 0.0;
uniform float dashes = 14.0;
uniform float glow = 0.0;

void fragment() {
	// CylinderMesh's V runs from its top (+Y, the link's end) to its bottom.
	float along = 1.0 - UV.y;
	if (dashed > 0.5 && fract(along * dashes) > 0.5) {
		discard;
	}
	float light = 0.0;
	if (speed > 0.0) {
		light = smoothstep(0.8, 1.0, fract(along * pulses - TIME * speed));
	}
	vec3 c = mix(color.rgb, vec3(1.0, 0.95, 0.82), light * 0.8);
	c = mix(c, glow_color.rgb, glow * (0.55 + 0.45 * sin(TIME * 1.6)));
	ALBEDO = c;
	ALPHA = clamp((ink * color.a + light * 0.3) * fade, 0.0, 1.0);
}
```

```gdscript
	for l: Dictionary in _snap["links"]:
		var a: Vector3 = _pos.get(String(l["from"]), Vector3.ZERO)
		var b: Vector3 = _pos.get(String(l["to"]), Vector3.ZERO)
		if a.is_equal_approx(b):
			continue
		var key := [String(l["from"]), String(l["to"])]
		key.sort()
		if int(pairs[key]) > 1:  # both ways between the same spheres: side by side
			var side := (b - a).cross(Vector3.UP).normalized() * _repo.bal("ledger_pair_offset_m")
			var sgn := 1.0 if String(l["from"]) == key[0] else -1.0
			a += side * sgn
			b += side * sgn
		_thread_mi[String(l["id"])] = _add_thread(l, a, b, running)


func _add_thread(l: Dictionary, a: Vector3, b: Vector3, running: Dictionary) -> MeshInstance3D:
	var mesh := CylinderMesh.new()
	var r := _width(l)
	mesh.top_radius = r
	mesh.bottom_radius = r
	mesh.height = a.distance_to(b)
	mesh.radial_segments = 8
	mesh.rings = 1
	var mat := ShaderMaterial.new()
	mat.shader = THREAD_SHADER
	mat.set_shader_parameter("color", _thread_color(l))
	mat.set_shader_parameter("ink", _ink(l))
	var planned := String(l["status"]) == "planned"
	mat.set_shader_parameter("dashed", 1.0 if planned else 0.0)
	mat.set_shader_parameter("dashes", _repo.bal("ledger_dashes"))
	mat.set_shader_parameter("pulses", _repo.bal("ledger_light_pulses"))
	var flowing := not planned and l["flow"] != null and int(l["flow"]) > 0 \
		and String(Ledger.link_row(_repo, String(l["type"])).get("resolver", "")) != "court_relations"
	var width_t := inverse_lerp(_repo.bal("ledger_thread_width_min"), _repo.bal("ledger_thread_width_max"), r)
	mat.set_shader_parameter("speed", _repo.bal("ledger_light_speed") * (0.4 + 0.6 * width_t) if flowing else 0.0)
	var loop_kind := String(running.get(String(l["type"]), ""))
	if loop_kind != "":
		mat.set_shader_parameter("glow", 1.0)
		mat.set_shader_parameter("glow_color", _pal["loop_" + loop_kind])
	var mi := MeshInstance3D.new()
	mi.mesh = mesh
	mi.material_override = mat
	var up := (b - a).normalized()
	var ref := Vector3.RIGHT if absf(up.dot(Vector3.RIGHT)) < 0.9 else Vector3.FORWARD
	var x := ref.cross(up).normalized()
	mi.transform = Transform3D(Basis(x, up, x.cross(up)), (a + b) * 0.5)
	_threads_root.add_child(mi)
	return mi


func _apply_focus_fade() -> void:
	var near := {}
	if _selected != "":
		near[_selected] = true
		for l: Dictionary in _snap.get("links", []):
			if String(l["from"]) == _selected or String(l["to"]) == _selected:
				near[String(l["from"])] = true
				near[String(l["to"])] = true
	var faint := _repo.bal("ledger_focus_fade")
	for id: String in _sphere_mi:
		var mat: StandardMaterial3D = (_sphere_mi[id] as MeshInstance3D).material_override
		var base: Color = _sphere_material(_nodes[id]).albedo_color
		mat.albedo_color.a = base.a * (1.0 if near.is_empty() or near.has(id) else faint)
	for l: Dictionary in _snap.get("links", []):
		var mi: MeshInstance3D = _thread_mi.get(String(l["id"]))
		if mi == null:
			continue
		var lit := near.is_empty() or (near.has(String(l["from"])) and near.has(String(l["to"])))
		(mi.material_override as ShaderMaterial).set_shader_parameter("fade", 1.0 if lit else faint)

func _apply_camera() -> void:
	_camera.transform = _orbit.pose()


func _process(delta: float) -> void:
	if _ease_left > 0.0:
		_ease_left = maxf(_ease_left - delta, 0.0)
		var t := 1.0 - _ease_left / maxf(_repo.bal("ledger_front_ease_s"), 0.001)
		_orbit.yaw = lerpf(_ease_from.x, 0.0, t)
		_orbit.pitch = lerpf(_ease_from.y, _repo.bal("ledger_camera_pitch_deg"), t)
		_apply_camera()
	if not _camera.transform.is_equal_approx(_last_pose):
		_last_pose = _camera.transform
		_update_hud()


func _update_hud() -> void:
	var entries: Array = []
	var order: Array = _nodes.keys()
	order.sort_custom(func(a: String, b: String) -> bool:
		return _rank(a) < _rank(b) if _rank(a) != _rank(b) else a < b)
	for id: String in order:
		var at: Variant = screen_pos_of(id)
		if at == null:
			continue
		entries.append({"text": String(_nodes[id]["label"]), "at": (at as Vector2) + Vector2(0, -18),
			"strong": id == _selected or id == String(_snap.get("focus_id", ""))})
	_hud.show_entries(entries)


func _rank(id: String) -> int:
	if id == _selected:
		return 0
	if id == String(_snap.get("focus_id", "")):
		return 1
	return 2 if not bool(_nodes[id]["instance"]) else 3

func _ray(pos: Vector2) -> Array:
	var px := LedgerPick.screen_to_viewport(pos, _window_scale())
	return [_camera.project_ray_origin(px), _camera.project_ray_normal(px)]


func _pick(pos: Vector2) -> Dictionary:
	var ray := _ray(pos)
	var spheres: Array = []
	for id: String in _nodes:
		spheres.append({"id": id, "pos": _pos[id], "radius": _radius(_nodes[id])})
	var threads: Array = []
	for l: Dictionary in _snap.get("links", []):
		if _thread_mi.has(String(l["id"])):
			threads.append({"id": String(l["id"]), "a": _pos[String(l["from"])], "b": _pos[String(l["to"])],
				"radius": maxf(_width(l), 0.25)})
	return LedgerPick.pick(ray[0], ray[1], spheres, threads)


func _gui_input(event: InputEvent) -> void:
	if _repo == null:
		return
	if event is InputEventMouseButton:
		_on_button(event as InputEventMouseButton)
	elif event is InputEventMouseMotion and _button != 0:
		_on_drag(event as InputEventMouseMotion)
	elif event is InputEventMagnifyGesture:
		_orbit.zoom(1.0 / maxf((event as InputEventMagnifyGesture).factor, 0.01))
		_apply_camera()
		accept_event()
	elif event is InputEventPanGesture:
		_orbit.pan(-(event as InputEventPanGesture).delta * _repo.bal("ledger_pan_gesture_px"),
			_orbit.metres_per_px(_camera.fov, size.y))
		_apply_camera()
		accept_event()


func _on_button(mb: InputEventMouseButton) -> void:
	if mb.pressed and mb.button_index in [MOUSE_BUTTON_WHEEL_UP, MOUSE_BUTTON_WHEEL_DOWN]:
		var f := _repo.bal("ledger_zoom_factor")
		_orbit.zoom(1.0 / f if mb.button_index == MOUSE_BUTTON_WHEEL_UP else f)
		_apply_camera()
		accept_event()
		return
	if not mb.button_index in [MOUSE_BUTTON_LEFT, MOUSE_BUTTON_RIGHT]:
		return
	accept_event()
	if mb.pressed:
		_button = mb.button_index
		_press_at = mb.position
		_moved = false
		_drag_id = ""
		if mb.button_index == MOUSE_BUTTON_LEFT:
			var hit := _pick(mb.position)
			if String(hit.get("kind", "")) == "sphere":
				_drag_id = String(hit["id"])
				if mb.double_click:
					_button = 0
					drill_requested.emit(_drag_id)
		return
	if _button != mb.button_index:
		return
	var was := _button
	_button = 0
	if _moved:
		return
	var hit := _pick(mb.position)
	if was == MOUSE_BUTTON_RIGHT:
		if not hit.is_empty():
			orders_requested.emit(String(hit["id"]), mb.position)
		return
	match String(hit.get("kind", "")):
		"sphere":
			select(String(hit["id"]))
			sphere_selected.emit(String(hit["id"]))
		"thread":
			thread_selected.emit(String(hit["id"]))
		_:
			select("")
			sphere_selected.emit("")


func _on_drag(mm: InputEventMouseMotion) -> void:
	if not _moved and mm.position.distance_to(_press_at) < CLICK_SLOP:
		return
	_moved = true
	if _button == MOUSE_BUTTON_RIGHT:
		_orbit.turn(mm.relative.x, mm.relative.y, _repo.bal("ledger_turn_deg_per_px"))
	elif _drag_id != "":
		_drag_to(_drag_id, mm.position)
	else:
		_orbit.pan(mm.relative, _orbit.metres_per_px(_camera.fov, size.y))
	_apply_camera()
	accept_event()


## A dragged sphere slides on its own layer's plane; the drag is for this
## viewing only and is never saved (spec §6.2).
func _drag_to(id: String, pos: Vector2) -> void:
	var ray := _ray(pos)
	var o: Vector3 = ray[0]
	var d: Vector3 = ray[1]
	var y := (_pos[id] as Vector3).y
	if absf(d.y) < 1e-4:
		return
	var t := (y - o.y) / d.y
	if t <= 0.0:
		return
	_pos[id] = o + d * t
	(_sphere_mi[id] as MeshInstance3D).position = _pos[id]
	_build_threads()
	_apply_focus_fade()
	_update_hud()
```

```gdscript
# scripts/ui/ledger_screen.gd
class_name LedgerScreen
extends Control
## The LEDGER screen (spec 2026-09-30-ledger-ontology-design §6.1): laid
## exactly over the map panel (GameRoot fits it), so the left column keeps
## FACTS and the right column keeps the council (invariant 10). The only
## LEDGER piece that touches Game: it asks Ledger for a snapshot on every
## state change while open, fills the left column, and runs an order
## through Game.try_execute.

signal show_requested(subject: Dictionary)
signal closed

var _lens := "economy"
var _focus_id := ""
var _snap: Dictionary = {}
var _detail: MapDetailPanel
var _bound := false

@onready var _view: LedgerView3D = %View
@onready var _orders: LedgerOrderMenu = %Orders


func _ready() -> void:
	visible = false
	(%Frame as PanelContainer).add_theme_stylebox_override("panel",
		UiPalette.panel_style(UiPalette.BORDER_GOLD, 1, 0, "map"))
	UiPalette.style_title(%Title, 18)
	%Close.pressed.connect(close)
	%Front.pressed.connect(func() -> void: _view.front_view())
	%Back.pressed.connect(back)
	_view.sphere_selected.connect(_on_sphere)
	_view.thread_selected.connect(_on_thread)
	_view.drill_requested.connect(drill)
	_view.orders_requested.connect(_on_orders)
	_orders.chosen.connect(_on_order)


func view() -> LedgerView3D:
	return _view


func snapshot() -> Dictionary:
	return _snap


func lens() -> String:
	return _lens


func open(detail: MapDetailPanel) -> void:
	if not _bound:
		_bound = true
		_view.bind(Game.data)
		_build_lenses()
		Game.state_changed.connect(refresh)
	if _detail != null and _detail.list_row_chosen.is_connected(drill):
		_detail.list_row_chosen.disconnect(drill)
	_detail = detail
	_detail.list_row_chosen.connect(drill)
	visible = true
	_view.set_active(true)
	_rebuild(false)


func close() -> void:
	if not visible:
		return
	visible = false
	_view.set_active(false)
	if _detail != null:
		_detail.show_entry({})
	closed.emit()


func refresh() -> void:
	if visible:
		_rebuild(true)


func set_lens(lens_id: String) -> void:
	_lens = lens_id
	_focus_id = ""
	for b in %Lenses.get_children():
		(b as Button).set_pressed_no_signal(String(b.name) == "Lens_" + lens_id)
	_rebuild(false)


func drill(id: String) -> void:
	if id.begins_with("type:") or id.begins_with("more:") or id == "":
		return
	_focus_id = id
	_rebuild(false)


func back() -> void:
	_focus_id = ""
	_rebuild(false)


func _rebuild(keep_camera: bool) -> void:
	_snap = Ledger.snapshot(Game.data, Game.state, _lens, {"id": _focus_id} if _focus_id != "" else {})
	if bool(_snap["focus_lost"]):
		_focus_id = ""
	_view.show_snapshot(_snap, keep_camera)
	%Back.visible = _focus_id != ""
	%Crumb.text = "" if _focus_id == "" else LedgerResolvers.label_of(Game.data, Game.state, _focus_id)


func _build_lenses() -> void:
	for row: Dictionary in Game.data.ledger_lenses:
		var b := Button.new()
		b.name = "Lens_" + String(row["lens"])
		b.text = String(row["label"])
		b.toggle_mode = true
		b.button_pressed = String(row["lens"]) == _lens
		UiPalette.flat_tab(b)
		var lens_id := String(row["lens"])
		b.pressed.connect(func() -> void: set_lens(lens_id))
		%Lenses.add_child(b)


func _on_sphere(id: String) -> void:
	if _detail == null:
		return
	if id == "" or id.begins_with("more:"):
		_detail.show_entry({})
		return
	var row := Ledger.type_row(Game.data, Ledger.type_of(id))
	if id.begins_with("type:") and String(row.get("instances", "")) != "":
		var rows: Array = []
		var cap := int(Game.data.bal("ledger_list_cap"))
		for r: Dictionary in LedgerResolvers.instances(String(row["instances"]), Game.data, Game.state):
			if rows.size() >= cap:
				break

			_detail.show_entry(LedgerCards.thread_entry(Game.data, Game.state, l))
			return


func _on_orders(id: String, at: Vector2) -> void:
	var rows := Ledger.actions_for(Game.data, id)
	if rows.is_empty():
		return
	_orders.open_for(id, rows, _view.global_position + at)


func _on_order(node_id: String, row: Dictionary) -> void:
	if bool(row["needs_map"]):
		var subj := LedgerCards.subject_of(Game.data, Game.state, node_id)
		if subj.is_empty():

		return

	if not bool(res["ok"]):
		_detail.show_entry({"title": String(row["label"]), "lines": [String(res["error"])]})
```
