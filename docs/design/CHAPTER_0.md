## 0. 一句话概括

新王登基的第一次御前会议上，情报总管报告首都隔壁的行省出现秘密结社；玩家用九个月查明真相、喂饱山谷、守住四个数字，在秋收日结算，在初冬做最后一个选择。

**本章完全不调用模型。** 所有叙述是预写文本（`Voicer.voice_event` 没有通往 API 的分支），所有玩家输入是固定按钮，所有数字是引擎算术。没有 API key 的玩家玩到的序章和有 key 的一模一样。

本章同时承担**新手教程**：每个节拍只引入一个系统概念（两个钱包、月结算、粮仓与民心、派系好感、特质分支、庄园层），自由指令留给第一章。

## 1. 它是怎么跑起来的（实现，不是计划）

| 东西 | 在哪 |
|---|---|
| 21 段正文（场景散文 + 标题） | `game_story/chapter_0/chapter_0_events.md`，**运行时加载** |
| 21 行事件表 | `data/chapter_events.csv` |
| 51 行选项表 | `data/chapter_event_choices.csv` |
| 16 行分支表 | `data/chapter_branches.csv` |
| 51 行结果台词 | `data/templates.csv`（`event_c0_*`） |
| 21 张插图的 prompt | `docs/references/art_prompt_library.md` §8.6（`V-35`~`V-55`）→ `assets/flux/event_art.csv` |
| 测试 | `tests/engine/test_chapter_zero.gd`（21 个用例） |

**没有新的 ChapterRunner，也没有第二套事件格式。** 本作已经有一整套事件系统——`EventSystem` 取事件、`TriggerDsl` 判条件、`EventEffects` 执行效果、`StorySource` 读散文、会见窗显示、存档带着走。序章是**这套系统里的一条链**，不是它旁边的第二套东西。为此对引擎只加了三样小东西：

1. `TriggerDsl`：`never`（只走链、永不被随机抽到）、`!` 取反、`trait_of=<席位或角色>:<特质>`（原来只有"朝堂上任何人有某特质"，而这里要问的是"**门口这个人**是不是老兵"）。
2. `EventEffects` 新增 `branch:<branch_id>` 算子：按 `data/chapter_branches.csv` 的顺序取**第一条成立的规则**，按该规则自己的 `ticks` 排期。整章的分叉都走它。
3. `GameState.new_campaign`：把 `chapter_events.csv` 里填了 `start_tick` 的那一拍排进日程。序章因此是每一局新游戏的开场，而不是随机抽到的。

章节事件**不在 `data/events.csv` 里**（那是按权重抽样的随机池，抽到一个剧情拍就乱序了），但在 `events_by_id` 里——链按 id 点名触发。`EventSystem` 读 `DataRepository.event_choices_all()`，两张表都看得见。

## 2. 剧情梗概

先王死在北境的战争里。新王阿尔德里克四十岁登基，第一次御前会议在春天的第一个月。

情报总管奎尔报告：首都隔壁的**比内特斯顿郡**——卢顿河谷，王室自己的瓦尔博弗省的邻郡——出现名为"麦捆兄弟会"的秘密结社，截获的信里写着"待到麦熟，粮仓当归于播种之人"。玩家的同父异母兄弟、自先王的战争以来一直掌管河谷粮仓钥匙的**托马斯公爵**，主动提出代为处理。他从容得过分。

无论玩家选择镇压、暗查还是召见，都可能拿到同一件东西：一本手抄账簿。它揭示过去三年河谷的收成被瞒报了近两成五到四成，差额经**大法官奥德温·里夫**之手，沿河北运，卖给了先王死在其手里的北方女王。所谓秘密结社，只是磨坊工和织工私下凑粮互助，熬过两个饥荒冬天。账簿边缘有一行更细的蓝黑色笔迹——王的堂妹**伊索尔德**一直在用自己的嫁妆替磨坊工付粮钱，从没告诉过他。

托马斯随后要求继续掌管河谷粮仓，并且给了玩家一条退路：一个数字。留着钥匙，或者收回钥匙、用明年秋收的账目证明王室数得更准。御前会议记下四个数字。

此后九个月里，青黄不接时的赈粮、织工的特许状、北方女王的婚约、秋天扣下不发的税粮，每一个节点都在权力、金钱、民心和亲情之间做交换。

秋收日账目摊开在长桌上。初冬的那一晚，托马斯私下来找他，桌上一根蜡烛，账簿合着。

## 4. 时间 — 春天开局，秋收结算

原稿写的是"冬至前夜开局、四个季度"。本作的历法（`Calendar`）是：**一个 tick = 30 天 = 一个月，12 个月一年，tick 1 是第一年的春天第一个月**。所以序章从春天开始，在秋收结算——这也更对：新王在春耕时登基，在收成时被审判。

| Tick | 日期 | 节拍 |
|---|---|---|
| 1 | Spring 1 | C0-01 石厅的第一次御前会议 |
| 2 | Spring 31 | C0-02 麦捆兄弟会 |
| 3 | Spring 61 | C0-03S/L/A 或 C0-04S/A —— 所选的路 |
| 4 | Summer 1 | C0-05 账簿 |
| 5 | Summer 31 | C0-06 公爵的提议 —— **四个数字写下来** |
| 6 | Summer 61 | C0-07 青黄不接 |
| 7 | Autumn 1 | C0-08 织工的特许状 / C0-08S 囚室里的名单 |
| 8 | Autumn 31 | C0-09 北方的婚约 |
| 9 | Autumn 61 | C0-11H/T 秋收之日 —— **或者** C0-10 扣下的税粮（若钥匙仍在公爵手里） |
| 10 | Winter 1 | C0-12 最后的清算（若税粮被扣，则是秋收） |
| 11–12 | Winter 31/61 | 结局 |

**阻挠要付一个月。** 扣下国王自己的税车，之后每一拍都晚一个月，账目在初冬第一周读出来而不是在打谷场上。两条"永远打不开账簿"的捷径（烧掉、留在奎尔的保险柜里）等两个月而不是一个月，所以怎么玩这一章都守着同一本历书。

链条留空的月份属于普通随机事件池——序章不会把一年都占满。

## 5. 地点 — 地图包自己的地方

原稿的 `hegu`（河谷行省）和 `greywheat`（灰麦镇）是占位。实际落到：

| 原稿 | 本作 | 依据 |
|---|---|---|
| 河谷行省 | **比内特斯顿郡** `bineterston` | 人口 71,084，面积 719，**与首都瓦尔博弗直接接壤**（`MapManors.province_neighbours`），生物群系 6（温带落叶林 → `manor_focus.csv` 的谷物默认地），没有绑给任何议会家族（`house_bindings.csv`），所以给谁当总督都不打架 |
| 河谷 | **卢顿河** `Louthton` | `geography/rivers.csv`，离首都 5.4 px、离郡治 5.4 px，全realm离首都最近的一条河 |
| 灰麦镇 | **威克比** `Wickleby` 庄园 | 该郡两块谷物庄园之一，16,661 人，没有城镇——所以它是个**庄园**，正是游戏建模的那个单位，玩家在 MANORS 层点得到它 |
| （第二块谷地） | **曼德福** `Mandfow` | 9,744 人，谷物 |
| 郡治 | **比内特斯顿** 镇 | 12,299 人，有城墙的河港 |
| 东马克 | `{neighbor_realm}` | 架构约束 5：散文永远不写王国名。北方女王的纹章是**红底银镰刀**（`assets/flux/arms_prompts.csv` A-005），本国是**红底金浑天仪**（A-004）——一把收割的镰刀盖在偷运粮食的账上，是地图包白送的象征 |

**托马斯是"王命总督"，不是领主。** `house_bindings.csv` 里 Valorin 只绑首都省；再绑一个省，`MapManors.controlled_provinces` 就会把它算成王室自己的（王室家族就是玩家家族），那和剧情正相反。所以他掌的是**粮仓钥匙这个官职**，不是土地所有权——这恰好就是 C0-06 那场戏在争的东西，一行数据都不用改。

## 6. 四个数字 · 卢顿之约

原稿的目标（国库 ≥ 5,000、粮仓 ≥ 12,000 石）是照一个**不存在的经济**写的：它假设开局 3,200 金。真实开局是（`tools/chapter0_numbers.gd`，beria 包，seed 44）：

```
treasury 2,177   grain(民用池) 13,272   strategic 726
lord_gold 861    unrest 0           legitimacy 50   contentment 50
月结算：王室 +1,565 金 / +4,270 民用货物，领主purse +364 金
```

**什么都不做**，九个月后是 16,262 金、51,834 民用货物、动乱 0。原稿的数字会被闭着眼睛达成。

所以四个数字重定为一份**预算**而不是一场苦工，在 C0-12 的分支里一次判定：

| | 条件 | 它考的是什么 |
|---|---|---|
| 钱袋 | `treasury>12000` | 王室拿全realm的份额，减去朝廷开销；本章总共能花掉约 6,000 |
| 粮仓 | `grain>45000` | 民用池：粮食、木材、布匹。赈粮花的是它，秋收补的也是它 |
| 太平 | `unrest<25` | 开局是 0。镇压 +18，封镇 +12，审判传教士 +12——毁掉它最快的办法是暴力 |
| 民心 | `peasant_contentment>45` | 开局 50。赈粮 +8，卖粮 −6，闭仓 −12 |

四项互相牵制：镇压最便宜（不花钱）但同时打掉太平和民心；赈粮买民心但吃掉六千民用货物；卖种粮赚钱但两头都掉。没有一条路四项全赢。

**封口费买不到这个约定。** C0-12 的"私下了结"给 1,500 金，但那一行的 `branch:` 算子**排在 gold 之前**——分支读完状态，钱才落袋。测试 `test_hush_money_cannot_buy_the_bond` 钉住这一点。

## 7. 四个结局

`data/chapter_branches.csv` 的 `c0_br_ending`，从上往下第一条成立的规则赢：

| 顺序 | 条件 | 结局 | 留下 |
|---|---|---|---|
| 1 | 四数达成 **且** 走过镇压路线 | **C0-15 铁腕之冠** | `brotherhood_underground`，动乱 +5，民心 −8 |
| 2 | 四数达成 **且** 出示过账簿 | **C0-13 明君之始** | `aymer_resentful`，正统 +5，动乱 −5，公爵好感 −20 |
| 3 | 四数达成 | **C0-14 妥协之王** | `tomas_retired`，正统 −2 |

镇压排在账簿之前是故意的：烧掉磨坊之后再拿出真相，赎不回来。

## 8. 教学：每一拍教一件事

| 节拍 | 教的东西 |
|---|---|
| C0-01 | 两个钱包（王室国库 vs 领主purse）、议会席位、好感 |
| C0-02 | 一个选择有多个后果维度；随从的特质会**多给你一个选项**（`trait_of` 开在 `requires` 上） |
| C0-03/04 | 情报、好感、安全通行；分叉都是**看得见的**，不是暗骰——海尔上尉的 `veteran` 让他当着玩家的面提出"先清场"，不选才会挨刀；奎尔报不报实情，取决于玩家在第一次御前会议上有没有先听人说话 |
| C0-05 | 读账、证据、人际关系图 |
| C0-06 | 目标与截止；月结算怎么读 |
| C0-07 | 民用池 = 粮食；青黄不接时赈济的价格，和它在秋收时买回来的东西 |
| C0-08 | 贸易与特许；得罪一个派系的代价 |
| C0-09 | 外交、联姻、用证据反将一军 |
| C0-10 | 派系升级到公开抗命；军事选项的价格 |
| C0-11 | 秋收结算、四个数字怎么被读出来 |
| C0-12 | 最后一个道德选择，没有标准答案 |

链条空出来的月份（tick 4 的某些路线、以及每条路线之间）留给玩家在地图上**自己动手**：MANORS 层点开威克比和曼德福，用 `WORK` 按钮改主产、用 BUILD 菜单造磨坊和粮仓——这些订单不经过模型，直接走 `Game.try_execute`。

| 20 张油画风插图，另有 6 张角色参考 | 21 张插图（一拍一张），本作的彩铅风；角色参考不做 | 21 个角色的立绘（chip + full）**已经全部存在**于 `assets/portraits/`。风格必须是 `STYLE_CORE.txt` 的彩铅，"写实历史油画"和游戏里其他任何一张图都不搭 |

### 两处死内容，改成了玩家的选择

原稿把两个分支挂在特质上：情报总管是否 `ambitious`、侍卫统领是否 `vigilant`。映射到本作的花名册之后，这两条判定的答案是**固定的**——奎尔没有 `amb_ruthless`，海尔有 `veteran`——于是"奎尔的提议"和"偏厅里的刀"两拍永远不会出现。而且 `RANDOM_EVENTS.md` 的设计规则本来就写着：**门要开在选项上，不要在玩家看不见的地方掷骰**。

所以：C0-02 多了第四个选项"让海尔上尉先把偏厅清一遍"，它的出现条件是 `trait_of=char_captain_hale:veteran`——特质决定这个选项**存不存在**，而要不要用是玩家的事；不用（或者门口没有老兵）就会挨那一刀。奎尔那条改成挂在玩家自己的第一个决定上：C0-01 选"先听每个人说"会留下 `c0_council_heard`，奎尔就把账簿直接交上来；否则这个 `paranoid|schemer|lowborn` 的人会先把它收进自己的保险柜。

### 顺手修掉的 bug

**标题一直是 `[missing template: event_ev_01]`。** `events.csv` 的 `title_key` 指向 `event_<id>`，而 `test_event_content.gd` **明令禁止** templates.csv 里出现这个 key（防止散文和标题漂移）——于是每个事件的横幅都显示占位符。现在标题从散文文档自己的标题行来（`StorySource.parse_titles` → `DataRepository.event_titles`），随机池里那 20 个事件因此也一起有了正确的标题。

**事件正文从中间开始读。** 会见窗每一拍都滚到最新一行，这对对话是对的，对事件是错的：一段事件散文是一个整块，玩家被直接丢到中间。散文是经 voicer **延迟**送达的，所以这个判断必须放在 `_say` 里（文字落地之后），而不是 `_render_beat` 的末尾（那时还没落地）。

**插图就是事件的脸。** 装了图之后，会见窗顶端是横幅插图，左边那张圆桌立绘就退场了——在剧情拍里它是同一个房间的第二张图，而它下面的档案属于一个叫"议会"的说话人。散文因此拿到整幅宽度，讲话框有了下限（一开场看得见六行而不是两行）。没装图的事件维持原样（立绘、没有横幅），所以没有美术的检出仍是一个完整的界面。`tests/ui/test_ui_rework.gd` 钉住最宽的情况：C0-02 的四个选项加一条 1280×533 的横幅，窗口和最后一个选项都必须在视口里。

## 12. 美术生产记录（给下一个画事件图的人）

五轮才收敛。每一轮暴露的都是**风格核心管不住的一类漂移**，写在这里省得重犯（同样的三条已经进了 `.claude/skills/visual-review/taste.md`）：

1. **第一轮**：人物站在空白奶油纸前，账簿/请愿书上全是假文字。→ 画布补上"场景自己的背景要画满、不许留白纸"；所有带纸的 prompt 一律把纸**合上、折起、背过去、只露封蜡**，并明写"看不见任何字"。
2. **第二轮**：时代漂移——拿破仑制服、维多利亚裙、19 世纪会议室。`STYLE_CORE` 在最前面说的"12–14 世纪"被场景名词（livery、ministers、travelling gown）盖过去了。→ 把时代当作**硬约束写进画布**，因为画布拼在 prompt 的**末尾**，抢得过场景词。
3. **第三轮**：上一条写过头了。画布里那串"锁子甲、头盔、鸢形盾"**对每一张图都生效**——大臣成了戴兜帽的士兵，递请愿书的织工成了持矛卫兵，跪着的传教士自己也戴上了王冠。→ 画布只**禁止**错误时代，不**规定**穿什么；"没被场景点名为士兵的人不许穿甲"，需要士兵的五张自己写盔甲。
4. **第四轮**（owner：手和脸很糟）：这是**构图问题，不是采样问题**——同 seed 下 32 步对 20 步几乎没差别。一条 12:5 的宽带里七张脸十四只手，4B 模型必崩。→ 画布规定"最多三个清晰人物、其余小而虚"，并且**手要有交代**：平放且手指并拢、交叠、握住一个点名的东西，或者干脆出画。七张重新构图（御前会议改成马尔文的背影、公爵的提议改成越肩、最后清算干脆不要脸只留两只手和一根蜡烛——那张成了全套最好的一张）。
5. **第五轮**：剩下四张的个案。人物会被画两遍（→ 明写"画面里只有三个人"）；人多的场面焦点会丢（→ 把焦点人物点名，其余"小而虚"）；画面边缘那只手总是多一根指头（→ 让它出画，或者换一稿）。

另外两条零碎：Flux 把 `corn` 画成玉米（麦田一律写 `wheat` + `no maize`）；公爵的 `parti-coloured cotehardie` 总被画成带肩章的轻骑兵制服（在事件图里改写成"黑袍+金绣襟边、无任何肩部装饰"）。

`assets/flux/event_art.csv` 的 `seed` 列钉住了每张装进去的那一稿，想换稿只改那一列再跑一次 `install_map_art.py events`。
