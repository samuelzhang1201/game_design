# P1.2 — encounter clock bridge and panel

Status: local implementation, independent review and final local gates accepted; PR CI pending.

## Delivered behavior

First contact interrupts the resumable day before casualties. GameRoot discards accumulated elapsed time and exposes a central encounter window. It shows own troops and only enemy strength available through WarFolio/Intel; its buttons emit requests. Deployment opens the existing war room and returning restores the encounter. A valid confirmation releases only the battle hold and leaves the clock manually paused. Resume preserves the chosen1×/2×/4× speed, completes the old day first, then waits the normal interval for the next day. Saved encounters restore the same token and hold; multiple encounters require individual confirmation. Completed-day missive/work notices and month reports retain their pre-interruption baseline.

The scene was authored and adjusted through the actual isolated Godot editor using the existing MCP adapter with temporary ports. Open script buffers were checked against disk before saving. Temporary project keys, native plugin files and private plugin configuration were removed afterward; the exact project baseline and all persistent MCP configuration hashes were verified. Main editor/services remained untouched.
